后现代主义

Postmodernism

质疑现代主义的唯一正确答案，以历史引用、戏仿、符号和混杂规则重获表达自由。

一眼识别：古典符号与大众图像混搭、断裂网格、夸张色彩和反功能装饰。

01 · CORE DEFINITION

后现代主义解决什么视觉问题

视觉任务质疑现代主义的唯一正确答案，以历史引用、戏仿、符号和混杂规则重获表达自由
解决方式通过折衷式非对称层叠与多重视觉中心、历史语汇、现代几何与通俗图形并置、刻意比例冲突、碎片化与不连续网格把抽象气质转化为稳定、可重复的画面规则。
核心气质不对称、反叛、拼贴、高饱和；视觉重点是古典符号与大众图像混搭、断裂网格、夸张色彩和反功能装饰。
边界它不等于简单加入“后现代主义元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别后现代主义

古典符号与大众图像混搭、断裂网格、夸张色彩和反功能装饰。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图折衷式非对称层叠与多重视觉中心

决定视线从哪里进入、信息按什么顺序被读取。

比例刻意比例冲突、碎片化与不连续网格

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型历史语汇、现代几何与通俗图形并置

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩中性色中插入互不调和的高饱和强调

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀主光配克制阴影，避免无依据的多光源

决定空间深度、材质可信度和戏剧程度。

字体衬线、无衬线与装饰字体的反规范混排

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质平面印刷、光泽材质与装饰纹理并置

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；后现代主义需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

折衷式非对称层叠与多重视觉中心

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“折衷式非对称层叠与多重视觉中心”搭建大结构，再添加彩色层压板等表面信息。

历史语汇、现代几何与通俗图形并置

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“历史语汇、现代几何与通俗图形并置”是否清楚，再补充色彩与材质。

刻意比例冲突、碎片化与不连续网格

作用控制主体的力量感、亲近感以及与环境的关系。

使用在草图阶段先锁定“刻意比例冲突、碎片化与不连续网格”，再进入细节；比例错误无法靠后期纹理补救。

衬线、无衬线与装饰字体的反规范混排

作用把风格延伸到标题和信息结构，影响阅读顺序与节奏。

使用让“衬线、无衬线与装饰字体的反规范混排”只承担标题和层级；正文仍需满足实际阅读尺寸。

中性色中插入互不调和的高饱和强调

作用建立第一情绪、视觉焦点和区域层级。

使用将“中性色中插入互不调和的高饱和强调”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

平面印刷、光泽材质与装饰纹理并置

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“平面印刷、光泽材质与装饰纹理并置”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#D96E9F

用于背景、最大形体或主要材质，承担后现代主义的整体气质。

辅助色 · 30%#3AA59A

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#E3C734

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“质疑现代主义的唯一正确答案，以历史引用、戏仿、符号和混杂规则重获表达自由”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造不对称感、反叛、冲撞与非主流态度、拼贴感、兴奋、活力与即时吸引的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把空间秩序、材料观念与公共体验；平面中的核心主题与叙事对象；产品功能、材料特征与使用体验作为核心内容；主体需要允许断裂网格和夸张山墙参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“不对称、反叛、拼贴”，并能让断裂网格、粉色和彩色层压板承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

需要长期阅读、低刺激、制度信任或严肃中立表达的场景不宜让后现代主义主导；可只保留色彩或局部材质作为强调。

具体风险

  • 不对称需要清晰的视觉重量平衡，否则容易被误读为随意摆放。
  • 反叛语气不适合强调稳定、权威和普适信任的正式沟通。
  • 高饱和色同时大面积使用会削弱信息层级，应明确主色和小面积强调色。

07 · COMPARISON

容易与哪些风格混淆

后现代主义 vs 波普艺术

后现代主义断裂网格；夸张山墙；粉色、青绿；彩色层压板。

波普艺术图像重复；粗黑轮廓；高饱和红黄蓝、强互补色；半调网点。

关键差异：后现代主义的识别重心是“古典符号与大众图像混搭、断裂网格、夸张色彩和反功能装饰”；波普艺术则是“高饱和原色、粗黑轮廓、网点、重复图像与商业符号”。先比较空间结构和边缘处理，再比较题材。

后现代主义 vs 孟菲斯设计

后现代主义断裂网格；夸张山墙；粉色、青绿；彩色层压板。

孟菲斯设计碎片散布；几何积木；亮粉、青绿；层压板。

关键差异：后现代主义的识别重心是“古典符号与大众图像混搭、断裂网格、夸张色彩和反功能装饰”；孟菲斯设计则是“彩色几何、波浪线、点阵纹样、冲突比例与不稳定平衡”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留断裂网格和 #D96E9F 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用断裂网格、夸张山墙、粉色和彩色层压板，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循后现代主义，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
折衷式非对称层叠与多重视觉中心、中性色中插入互不调和的高饱和强调、衬线、无衬线与装饰字体的反规范混排
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
历史语汇、现代几何与通俗图形并置、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
折衷式非对称层叠与多重视觉中心的层级逻辑、中性色中插入互不调和的高饱和强调、局部使用平面印刷、光泽材质与装饰纹理并置
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
历史语汇、现代几何与通俗图形并置、均匀主光配克制阴影，避免无依据的多光源、平面印刷、光泽材质与装饰纹理并置
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

10 · PROMPT RECIPE

Prompt 配方：逐项控制，而不是只写风格名

主体具体对象 + 动作/状态 + 使用场景；不要只写抽象情绪
构图折衷式非对称层叠与多重视觉中心
比例刻意比例冲突、碎片化与不连续网格
造型历史语汇、现代几何与通俗图形并置
色彩中性色中插入互不调和的高饱和强调；建议面积比例 55/30/15
光线均匀主光配克制阴影，避免无依据的多光源
材质平面印刷、光泽材质与装饰纹理并置
字体多字体混排、装饰衬线与无衬线并置；允许偏心或斜向排列，但必须保持视觉重量平衡
媒介明确写海报、品牌主视觉、数字界面或插画，不让模型自行猜测输出类型
排除项

无关风格混搭，通用模板感，主体与背景层级不清，不可读文字，所有颜色平均抢占注意力

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个后现代主义风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“断裂网格、夸张山墙、粉色与青绿、彩色层压板”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定后现代主义为主风格；冲突属性只保留一项，并明确风格强度。

错误写法后现代主义 + 波普艺术 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留后现代主义作为结构主导；如需混合，只让波普艺术负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约 1970–1995 年，欧美语境。主要来源包括波普艺术、符号学与对现代主义的批判。
关键转变质疑现代主义的唯一正确答案，以历史引用、戏仿、符号和混杂规则重获表达自由；视觉语言由此集中到折衷式非对称层叠与多重视觉中心、历史语汇、现代几何与通俗图形并置、刻意比例冲突、碎片化与不连续网格。
后续影响孟菲斯、解构主义、九十年代平面与互联网混搭。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
