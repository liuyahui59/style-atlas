01 · CORE DEFINITION

垃圾摇滚设计解决什么视觉问题

视觉任务以侵蚀字体、脏污纹理和非正式排版反抗数字设计的洁净与规则
解决方式通过不规则重叠与破损网格、被侵蚀的粗体排版、脏灰、暗褐与低饱和强调色把抽象气质转化为稳定、可重复的画面规则。
核心气质粗粝、反叛、不对称、低饱和；视觉重点是磨损文字、污渍划痕、低清照片、叠印和暗沉土色。
边界它不等于简单加入“垃圾摇滚设计元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别垃圾摇滚设计

磨损文字、污渍划痕、低清照片、叠印和暗沉土色。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图不规则重叠与破损网格

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型低清照片与侵蚀图形

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩脏灰、暗褐与低饱和强调色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀主光配克制阴影，避免无依据的多光源

决定空间深度、材质可信度和戏剧程度。

字体被侵蚀的粗体排版

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质低保真复印与粗纸纹理

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；垃圾摇滚设计需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

不规则重叠与破损网格

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“不规则重叠与破损网格”搭建大结构，再添加划痕污渍与复印颗粒等表面信息。

被侵蚀的粗体排版

作用把风格延伸到标题和信息结构，影响阅读顺序与节奏。

使用让“被侵蚀的粗体排版”只承担标题和层级；正文仍需满足实际阅读尺寸。

脏灰、暗褐与低饱和强调色

作用建立第一情绪、视觉焦点和区域层级。

使用将“脏灰、暗褐与低饱和强调色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

划痕、污渍与油墨渗漏

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“划痕、污渍与油墨渗漏”搭建大结构，再添加划痕污渍与复印颗粒等表面信息。

低保真复印与粗纸纹理

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“低保真复印与粗纸纹理”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#25231F

用于背景、最大形体或主要材质，承担垃圾摇滚设计的整体气质。

辅助色 · 25%#756B50

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#9E3D33

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以侵蚀字体、脏污纹理和非正式排版反抗数字设计的洁净与规则”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造粗粝感、反叛、冲撞与非主流态度、不对称感、沉静、含蓄与耐看的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把声音气质、艺人形象与现场氛围；活动主题、核心观点与行动号召；身份态度、廓形语言与材料观念作为核心内容；主体需要允许不稳定叠层与越界构图和低清照片与侵蚀图形参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“粗粝、反叛、不对称”，并能让不稳定叠层与越界构图、脏灰土褐与暗红和划痕污渍与复印颗粒承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

需要长期阅读、低刺激、制度信任或严肃中立表达的场景不宜让垃圾摇滚设计主导；可只保留色彩或局部材质作为强调。

具体风险

  • 粗粝纹理会降低小字号和细线的清晰度，应将文字置于干净底层。
  • 反叛语气不适合强调稳定、权威和普适信任的正式沟通。
  • 不对称需要清晰的视觉重量平衡，否则容易被误读为随意摆放。

07 · COMPARISON

容易与哪些风格混淆

垃圾摇滚设计 vs 朋克视觉

垃圾摇滚设计不稳定叠层与越界构图；低清照片与侵蚀图形；脏灰土褐与暗红；划痕污渍与复印颗粒。

朋克视觉反网格剪贴构图；撕纸照片与手绘符号；黑白与单一猩红；复印噪点胶带与折痕。

关键差异：垃圾摇滚设计的识别重心是“磨损文字、污渍划痕、低清照片、叠印和暗沉土色”；朋克视觉则是“撕纸拼贴、复印噪点、手写标语、安全别针和黑白红冲突”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留不稳定叠层与越界构图和 #25231F 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用不稳定叠层与越界构图、低清照片与侵蚀图形、脏灰土褐与暗红和划痕污渍与复印颗粒，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循垃圾摇滚设计，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
不规则重叠与破损网格、脏灰、暗褐与低饱和强调色、被侵蚀的粗体排版
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
低清照片与侵蚀图形、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
不规则重叠与破损网格的层级逻辑、脏灰、暗褐与低饱和强调色、局部使用低保真复印与粗纸纹理
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
低清照片与侵蚀图形、均匀主光配克制阴影，避免无依据的多光源、低保真复印与粗纸纹理
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个垃圾摇滚设计风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“不稳定叠层与越界构图、低清照片与侵蚀图形、脏灰土褐与暗红、划痕污渍与复印颗粒”。

错误写法低饱和克制配色、同时要求彩虹霓虹高饱和

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定垃圾摇滚设计为主风格；冲突属性只保留一项，并明确风格强度。

错误写法垃圾摇滚设计 + 朋克视觉 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留垃圾摇滚设计作为结构主导；如需混合，只让朋克视觉负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景1990 年代，欧美语境。主要来源包括另类摇滚、朋克与早期桌面出版。
关键转变以侵蚀字体、脏污纹理和非正式排版反抗数字设计的洁净与规则；视觉语言由此集中到不规则重叠与破损网格、被侵蚀的粗体排版、脏灰、暗褐与低饱和强调色。
后续影响运动品牌、音乐视觉和复古网页。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
