01 · CORE DEFINITION

藏传唐卡解决什么视觉问题

视觉任务依据严格仪轨和比例绘制宗教图像，以中心神祇和象征系统服务修行与传承
解决方式通过严格中心对称与嵌套框架、层级明确的比例组织、精确细线与平面设色把抽象气质转化为稳定、可重复的画面规则。
核心气质对称、精密、象征、高饱和；视觉重点是中心神祇、层级对称、密集光环、矿物宝石色与织锦边框。
边界它不等于简单加入“藏传唐卡元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#A83232

用于背景、最大形体或主要材质，承担藏传唐卡的整体气质。

辅助色 · 30%#225C7A

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#D1A63A

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“依据严格仪轨和比例绘制宗教图像，以中心神祇和象征系统服务修行与传承”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造对称感、精密感、象征感、兴奋、活力与即时吸引的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；宗教艺术中的核心主题与叙事对象；装饰中的核心主题与叙事对象作为核心内容；主体需要允许严格中心层级对称和神祇莲座光环与云纹参与叙事。

传播场景

适合主题明确的品牌主视觉、文化活动、编辑内容和展览传播；使用前应确认风格气质不会压过核心信息。

受众预期

适合关注文化语境、传统工艺和象征含义的受众；跨文化传播时必须解释符号来源，避免把传统元素当作通用装饰。

选择依据

如果内容同时需要“对称、精密、象征”，并能让严格中心层级对称、朱红群青石绿与金色和矿物颜料金线与织锦承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

当项目要求完全中性、跨文化无歧义或极高信息效率时，不宜让藏传唐卡覆盖全部界面；应以轻度借鉴为主。

具体风险

  • 对称布局稳定但容易缺少动势，可以用信息层级而不是破坏轴线来制造变化。
  • 精密结构对对齐和制作误差敏感，不适合缺少统一规范的临时拼接。
  • 象征元素依赖文化背景，跨地区传播前需要确认不会产生误读。

07 · COMPARISON

容易与哪些风格混淆

藏传唐卡 vs 敦煌艺术

藏传唐卡严格中心层级对称；神祇莲座光环与云纹；朱红群青石绿与金色；矿物颜料金线与织锦。

敦煌艺术藻井中心与连续叙事构图；飞天飘带与佛教图像；赭红石绿与土金；风化矿物壁画质感。

关键差异：藏传唐卡的识别重心是“中心神祇、层级对称、密集光环、矿物宝石色与织锦边框”；敦煌艺术则是“飞天飘带、藻井几何、矿物色壁画与连续叙事场景”。先比较空间结构和边缘处理，再比较题材。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
严格中心对称与嵌套框架、高饱和矿物色与金色、仪轨题记
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
神祇莲座光环与云纹、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
严格中心对称与嵌套框架的层级逻辑、高饱和矿物色与金色、局部使用细密颜料与织物底材质感
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
神祇莲座光环与云纹、均匀主光配克制阴影，避免无依据的多光源、细密颜料与织物底材质感
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个藏传唐卡风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“严格中心层级对称、神祇莲座光环与云纹、朱红群青石绿与金色、矿物颜料金线与织锦”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定藏传唐卡为主风格；冲突属性只保留一项，并明确风格强度。

错误写法藏传唐卡 + 敦煌艺术 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留藏传唐卡作为结构主导；如需混合，只让敦煌艺术负责一个明确变量，例如色彩或材质。
