01 · CORE DEFINITION

工艺美术运动解决什么视觉问题

视觉任务以诚实材料、手工劳动和整体设计回应工业化批量生产的审美贫乏
解决方式通过对称满版连续重复、扁平互锁的有机曲线、靛蓝、茜红与橄榄绿把抽象气质转化为稳定、可重复的画面规则。
核心气质有机、满版、装饰、手工；视觉重点是对称满版连续重复；扁平互锁的有机曲线；靛蓝、茜红与橄榄绿；手工造成的轻微不规则；木版压印与织物纤维感。
边界它不等于简单加入“工艺美术运动元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别工艺美术运动

对称满版连续重复；扁平互锁的有机曲线；靛蓝、茜红与橄榄绿；手工造成的轻微不规则；木版压印与织物纤维感。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图手工造成的轻微不规则

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型扁平互锁的有机曲线

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩靛蓝、茜红与橄榄绿

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀主光配克制阴影，避免无依据的多光源

决定空间深度、材质可信度和戏剧程度。

字体手工衬线字与图案一体化

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质木版压印与织物纤维感

提供触感、媒介和年代线索，增强风格可信度。

装饰密度对称满版连续重复

控制信息压力与观看速度；工艺美术运动需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

对称满版连续重复

作用控制观看速度、信息压力和画面节奏。

使用先划定阅读区，再安排“对称满版连续重复”；在缩略图和移动端分别检查信息压力。

扁平互锁的有机曲线

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“扁平互锁的有机曲线”是否清楚，再补充色彩与材质。

靛蓝、茜红与橄榄绿

作用建立第一情绪、视觉焦点和区域层级。

使用将“靛蓝、茜红与橄榄绿”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

手工造成的轻微不规则

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“手工造成的轻微不规则”搭建大结构，再添加木版压印与织物纤维感等表面信息。

木版压印与织物纤维感

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“木版压印与织物纤维感”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

手工衬线字与图案一体化

作用把风格延伸到标题和信息结构，影响阅读顺序与节奏。

使用让“手工衬线字与图案一体化”只承担标题和层级；正文仍需满足实际阅读尺寸。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以诚实材料、手工劳动和整体设计回应工业化批量生产的审美贫乏”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造流动、柔和与生长感、拥挤、压迫与持续刺激、精致、繁复与连续节奏、手工感的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把封面主题、章节气氛与文化内容；产品功能、材料特征与使用体验；空间秩序、材料观念与公共体验作为核心内容；主体需要允许对称满版连续重复和扁平互锁的有机曲线参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

适合重视自然、材料触感、手工价值和生活方式的受众；强调尖端效率或无瑕精度的内容需要谨慎使用。

选择依据

如果内容同时需要“有机、满版、装饰”，并能让对称满版连续重复、靛蓝、茜红与橄榄绿和木版压印与织物纤维感承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

小屏界面、密集数据表格、无障碍优先或制作预算有限的项目不适合完整复刻工艺美术运动；应先降低装饰密度。

具体风险

  • 满版结构容易挤压标题和功能信息，需要预先划定不可侵占的阅读区域。
  • 装饰元素需要服从结构，随意叠加容易只剩表面模仿。
  • 手工不等于无规则，需要保留重复方式、材料边界和制作逻辑。

07 · COMPARISON

容易与哪些风格混淆

工艺美术运动 vs 前拉斐尔派

工艺美术运动对称满版连续重复；扁平互锁的有机曲线；靛蓝、茜红与橄榄绿；木版压印与织物纤维感。

前拉斐尔派近景密集且浅空间；前景至远景保持近乎一致的锐度；锐利轮廓、精确纹样与微观细节；均匀明亮的冷调光线与极少雾化。

关键差异：工艺美术运动的识别重心是“对称满版连续重复；扁平互锁的有机曲线；靛蓝、茜红与橄榄绿；手工造成的轻微不规则；木版压印与织物纤维感”；前拉斐尔派则是“近景密集且浅空间；前景至远景保持近乎一致的锐度；锐利轮廓、精确纹样与微观细节；翡翠绿、朱红、群青与明亮白色；均匀明亮的冷调光线与极少雾化”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

明显使用

同时使用对称满版连续重复、扁平互锁的有机曲线、靛蓝、茜红与橄榄绿和木版压印与织物纤维感，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
手工造成的轻微不规则、靛蓝、茜红与橄榄绿、手工衬线字与图案一体化
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
扁平互锁的有机曲线、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
手工造成的轻微不规则的层级逻辑、靛蓝、茜红与橄榄绿、局部使用木版压印与织物纤维感
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
扁平互锁的有机曲线、均匀主光配克制阴影，避免无依据的多光源、木版压印与织物纤维感
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个工艺美术运动风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“对称满版连续重复、扁平互锁的有机曲线、靛蓝、茜红与橄榄绿、木版压印与织物纤维感”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定工艺美术运动为主风格；冲突属性只保留一项，并明确风格强度。

错误写法工艺美术运动 + 前拉斐尔派 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留工艺美术运动作为结构主导；如需混合，只让前拉斐尔派负责一个明确变量，例如色彩或材质。
