11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个法国新浪潮电影风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“实景游移、稳定精密构图、跳切或长镜头均可，应区分导演与左岸派等路线、即兴、古典表演、直接凝视、文字中断或非线性时间按作品选择、高反差黑白、柔和胶片色、强烈原色或克制彩色均有历史实例、16mm或35mm胶片、同步录音、实景表面、档案影像和可见剪辑断点”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定法国新浪潮电影为主风格；冲突属性只保留一项，并明确风格强度。

错误写法法国新浪潮电影 + 意大利新现实主义电影 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留法国新浪潮电影作为结构主导；如需混合，只让意大利新现实主义电影负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约1958年–1960年代中后期，影响延续，法国语境。主要来源包括意大利新现实主义、好莱坞类型片、让·鲁什、《电影手册》作者政策、轻便摄影与录音技术。
关键转变法国新浪潮由《电影手册》评论网络、左岸派及一批低成本制作在1950年代末推动，通过实景、轻便设备、声画自反、类型重写和非连续剪辑改变作者与制片方式。跳切和手持只是部分导演的手段，不能覆盖特吕弗、戈达尔、瓦尔达、雷乃等人的差异；视觉语言由此集中到实景游移、稳定精密构图、跳切或长镜头均可，应区分导演与左岸派等路线、即兴、古典表演、直接凝视、文字中断或非线性时间按作品选择、高反差黑白、柔和胶片色、强烈原色或克制彩色均有历史实例。
后续影响世界各地新浪潮、新好莱坞、作者电影、独立制作和当代非连续剪辑。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
