01 · CORE DEFINITION

白描解决什么视觉问题

视觉任务以单色线条的粗细、浓淡、转折与疏密独立完成结构和体积表达
解决方式通过开放留白与清晰轮廓层级、连续墨线的粗细、浓淡与转折变化、墨黑淡墨与纸白的单色关系把抽象气质转化为稳定、可重复的画面规则。
核心气质留白、线性、克制、手工；视觉重点是几乎不设色，以连续墨线的线宽、浓淡和节奏完整描述对象。
边界它不等于简单加入“白描元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别白描

几乎不设色，以连续墨线的线宽、浓淡和节奏完整描述对象。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图连续墨线的粗细、浓淡与转折变化

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型开放留白与清晰轮廓层级

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩墨黑、淡墨、纸白

决定第一情绪和区域层级，不能只作为最后滤镜。

光线不用写实投影并以线条疏密表达体积

决定空间深度、材质可信度和戏剧程度。

字体细雅书写

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质墨黑淡墨与纸白的单色关系

提供触感、媒介和年代线索，增强风格可信度。

装饰密度低密度、少量焦点与大面积呼吸空间

控制信息压力与观看速度；白描需要在识别度和可读性之间保持平衡。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#242321

用于背景、最大形体或主要材质，承担白描的整体气质。

辅助色 · 25%#8D8980

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#E8E1D2

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以单色线条的粗细、浓淡、转折与疏密独立完成结构和体积表达”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造疏朗、停顿与精神性、线性感、克制、安静与观看距离、手工感的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；叙事主题、人物关系与概念设定；专题观点、阅读节奏与文化内容作为核心内容；主体需要允许开放留白和线宽变化参与叙事。

传播场景

适合文化机构、高端品牌、出版专题、静态展陈等允许观众停留和细看内容的场景；强促销环境中需要额外建立焦点。

受众预期

适合关注文化语境、传统工艺和象征含义的受众；跨文化传播时必须解释符号来源，避免把传统元素当作通用装饰。

选择依据

如果内容同时需要“留白、线性、克制”，并能让开放留白、墨黑和细毫毛笔承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强促销、节庆、即时行动号召或需要在拥挤环境中抢夺注意力的项目，不适合只使用白描的低刺激表达。

具体风险

  • 留白必须与信息优先级配合，不能简单理解为空内容或低信息量。
  • 过度克制会削弱识别与情绪，在竞争激烈的信息环境中需要更明确的焦点。
  • 手工不等于无规则，需要保留重复方式、材料边界和制作逻辑。

07 · COMPARISON

容易与哪些风格混淆

白描 vs 文人水墨

白描开放留白；线宽变化；墨黑、淡墨；细毫毛笔。

文人水墨散点空间；书写性线条；墨黑、纸白；宣纸渗化。

关键差异：白描的识别重心是“几乎不设色，以连续墨线的线宽、浓淡和节奏完整描述对象”；文人水墨则是“墨色浓淡、书写性笔触、大面积留白与散点空间”。先比较空间结构和边缘处理，再比较题材。

白描 vs 工笔画

白描开放留白；线宽变化；墨黑、淡墨；细毫毛笔。

工笔画平稳留白构图；精谨线描与细密花鸟；矿物青绿与朱砂设色；绢本层染质感。

关键差异：白描的识别重心是“几乎不设色，以连续墨线的线宽、浓淡和节奏完整描述对象”；工笔画则是“细而稳定的轮廓、平整层染、精密花鸟人物与克制背景”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留开放留白和 #242321 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用开放留白、线宽变化、墨黑和细毫毛笔，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循白描，仅适合主视觉、封面和沉浸式核心场景。

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
连续墨线的粗细、浓淡与转折变化、墨黑、淡墨、纸白、细雅书写
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留

需要调整

数字界面

必须保留

需要调整

插画

必须保留
开放留白与清晰轮廓层级、不用写实投影并以线条疏密表达体积、墨黑淡墨与纸白的单色关系
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个白描风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“开放留白、线宽变化、墨黑与淡墨、细毫毛笔”。

错误写法大面积留白、同时填满复杂装饰和密集信息

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定白描为主风格；冲突属性只保留一项，并明确风格强度。

错误写法白描 + 文人水墨 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留白描作为结构主导；如需混合，只让文人水墨负责一个明确变量，例如色彩或材质。
