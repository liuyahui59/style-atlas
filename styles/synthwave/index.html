01 · CORE DEFINITION

合成波解决什么视觉问题

视觉任务重构八十年代电子音乐、街机、录像带与复古未来想象，营造夜行速度感
解决方式通过中心消失点与深透视网格、硬边剪影与水平分层、洋红、电青与橙色渐变把抽象气质转化为稳定、可重复的画面规则。
核心气质未来、几何、高饱和、怀旧；视觉重点是黑色地平线、紫红落日、透视网格、镀铬标题和跑车剪影。
边界它不等于简单加入“合成波元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

如何识别合成波

黑色地平线、紫红落日、透视网格、镀铬标题和跑车剪影。 判断时不要只看题材，要逐项核对下面的视觉结构。

轮廓与造型硬边剪影与水平分层

色彩洋红、电青与橙色渐变

决定第一情绪和区域层级，不能只作为最后滤镜。

材质光洁数字表面与轻微扫描纹

提供触感、媒介和年代线索，增强风格可信度。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

中心消失点与深透视网格

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“中心消失点与深透视网格”搭建大结构，再添加VHS 扫描线等表面信息。

硬边剪影与水平分层

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“硬边剪影与水平分层”是否清楚，再补充色彩与材质。

洋红、电青与橙色渐变

作用建立第一情绪、视觉焦点和区域层级。

使用将“洋红、电青与橙色渐变”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

深黑背景与强烈霓虹辉光

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“深黑背景与强烈霓虹辉光”塑造主体；不要叠加互相冲突的光源。

光洁数字表面与轻微扫描纹

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“光洁数字表面与轻微扫描纹”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#743EA8

用于背景、最大形体或主要材质，承担合成波的整体气质。

辅助色 · 30%#E14194

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#247EC1

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“重构八十年代电子音乐、街机、录像带与复古未来想象，营造夜行速度感”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造未来感与技术张力、精确、清晰与结构感、兴奋、活力与即时吸引、怀旧、时间感与文化记忆的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把声音气质、艺人形象与现场氛围；活动主题、核心观点与行动号召；世界观、角色系统与探索空间作为核心内容；主体需要允许中央地平线和条纹落日参与叙事。

传播场景

适合设计展览、教育传播、品牌系统与产品说明等需要把观点组织得清楚有序的场景。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“未来、几何、高饱和”，并能让中央地平线、霓虹紫和VHS 扫描线承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强调尖端技术、无瑕精度或高洁净医疗感的场景，需要谨慎使用合成波的旧化与低保真信号。

具体风险

  • 未来感元素更新很快，避免依赖短期流行的霓虹、镀铬或界面装饰。
  • 几何秩序过强可能显得僵硬，需要通过尺度变化或留白建立呼吸感。
  • 高饱和色同时大面积使用会削弱信息层级，应明确主色和小面积强调色。

07 · COMPARISON

容易与哪些风格混淆

合成波 vs 蒸汽波

合成波中央地平线；条纹落日；霓虹紫、洋红；VHS 扫描线。

蒸汽波中心拼贴；古典雕塑；粉紫、青蓝；VHS 噪点。

关键差异：合成波的识别重心是“黑色地平线、紫红落日、透视网格、镀铬标题和跑车剪影”；蒸汽波则是“粉紫青渐变、古典半身像、棕榈树、日文文字和低清旧电脑界面”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留中央地平线和 #743EA8 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用中央地平线、条纹落日、霓虹紫和VHS 扫描线，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循合成波，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
中心消失点与深透视网格、洋红、电青与橙色渐变、镀铬斜体字、街机像素字
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
硬边剪影与水平分层、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
中心消失点与深透视网格的层级逻辑、洋红、电青与橙色渐变、局部使用光洁数字表面与轻微扫描纹
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
硬边剪影与水平分层、深黑背景与强烈霓虹辉光、光洁数字表面与轻微扫描纹
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个合成波风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“中央地平线、条纹落日、霓虹紫与洋红、VHS 扫描线”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定合成波为主风格；冲突属性只保留一项，并明确风格强度。

错误写法合成波 + 蒸汽波 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留合成波作为结构主导；如需混合，只让蒸汽波负责一个明确变量，例如色彩或材质。
