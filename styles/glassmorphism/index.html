玻璃拟态

Glassmorphism

一眼识别：磨砂玻璃面板、透明叠层、柔和彩色背景与细白描边。

01 · CORE DEFINITION

玻璃拟态解决什么视觉问题

视觉任务以半透明表面、背景模糊和细亮边缘建立轻盈的数字层级
解决方式通过半透明磨砂平面叠层、背景模糊与清晰前景边缘、细薄高亮边框把抽象气质转化为稳定、可重复的画面规则。
核心气质未来、轻盈、系统化、低饱和；视觉重点是磨砂玻璃面板、透明叠层、柔和彩色背景与细白描边。
边界它不等于简单加入“玻璃拟态元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别玻璃拟态

磨砂玻璃面板、透明叠层、柔和彩色背景与细白描边。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图细薄高亮边框

决定视线从哪里进入、信息按什么顺序被读取。

比例细长、轻量并保留充足呼吸空间

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型背景模糊与清晰前景边缘

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩冷蓝淡紫与柔白

决定第一情绪和区域层级，不能只作为最后滤镜。

光线低对比柔和投影

决定空间深度、材质可信度和戏剧程度。

字体轻量无衬线界面字

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质半透明磨砂平面叠层

提供触感、媒介和年代线索，增强风格可信度。

装饰密度低密度、少量焦点与大面积呼吸空间

控制信息压力与观看速度；玻璃拟态需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

半透明磨砂平面叠层

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“半透明磨砂平面叠层”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

背景模糊与清晰前景边缘

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“背景模糊与清晰前景边缘”是否清楚，再补充色彩与材质。

细薄高亮边框

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“细薄高亮边框”搭建大结构，再添加磨砂玻璃背景模糊与亮边等表面信息。

低对比柔和投影

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“低对比柔和投影”塑造主体；不要叠加互相冲突的光源。

饱和色透过玻璃扩散

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#79A9CF

用于背景、最大形体或主要材质，承担玻璃拟态的整体气质。

辅助色 · 25%#A888C4

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#E2E5E9

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以半透明表面、背景模糊和细亮边缘建立轻盈的数字层级”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造未来感与技术张力、轻快、通透与呼吸感、系统化感、沉静、含蓄与耐看的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把数字产品概念、内容层级与交互状态；品牌主张、价值立场与核心产品；产品差异、消费情境与传播主张作为核心内容；主体需要允许半透明面板分层构图和圆角玻璃模块与悬浮界面参与叙事。

传播场景

适合文化机构、高端品牌、出版专题、静态展陈等允许观众停留和细看内容的场景；强促销环境中需要额外建立焦点。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“未来、轻盈、系统化”，并能让半透明面板分层构图、冷蓝淡紫与柔白和磨砂玻璃背景模糊与亮边承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强促销、节庆、即时行动号召或需要在拥挤环境中抢夺注意力的项目，不适合只使用玻璃拟态的低刺激表达。

具体风险

  • 未来感元素更新很快，避免依赖短期流行的霓虹、镀铬或界面装饰。
  • 系统规则应服务内容差异，避免所有页面因为过度一致而失去重点。
  • 低饱和可能不足以支撑促销、节庆或强行动号召，需要额外的强调色。

07 · COMPARISON

容易与哪些风格混淆

玻璃拟态 vs Y2K 未来复古

玻璃拟态半透明面板分层构图；圆角玻璃模块与悬浮界面；冷蓝淡紫与柔白；磨砂玻璃背景模糊与亮边。

Y2K 未来复古中心悬浮；液态曲面；银色、冰蓝；镀铬。

关键差异：玻璃拟态的识别重心是“磨砂玻璃面板、透明叠层、柔和彩色背景与细白描边”；Y2K 未来复古则是“银色镀铬、半透明塑料、椭圆轨道、像素字体与高光渐变”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留半透明面板分层构图和 #79A9CF 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用半透明面板分层构图、圆角玻璃模块与悬浮界面、冷蓝淡紫与柔白和磨砂玻璃背景模糊与亮边，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循玻璃拟态，仅适合主视觉、封面和沉浸式核心场景。

保持用户指定的主体、数量、动作、场景、身份与叙事关系；用户明确指定的构图、镜头、画幅与文字内容优先；不新增主体、人物、道具或叙事元素。以玻璃拟态作为唯一主导风格。必须同时满足四组控制：构图，仅调整用户已有元素的布局关系：半透明面板分层构图；不新增构图中提到的题材；造型，仅处理用户已有对象的轮廓、比例与结构：圆角玻璃模块与悬浮界面；不把其中的典型题材解释为新增内容；色彩，冷蓝淡紫与柔白；材质，磨砂玻璃背景模糊与亮边。执行细节：半透明磨砂平面叠层，背景模糊与清晰前景边缘，细薄高亮边框，低对比柔和投影，饱和色透过玻璃扩散。文字控制：仅在用户要求文字时使用轻量无衬线界面字；保持用户原文内容与可读性。

English AI-executable prompt

Preserve the user-defined subjects, count, actions, setting, identities, and narrative relationships. User-specified composition, camera, aspect ratio, and exact text take priority. Do not add subjects, props, or story elements. Use Glassmorphism as the sole dominant visual style. Required execution details: layered translucent frosted planes, blurred background with crisp foreground edges, thin luminous borders, low-contrast soft shadows, saturated color diffused through glass. Keep composition, form, palette, lighting, and surface treatment coherent. Apply style-appropriate typography only when the user requests text; otherwise add no text.

具体风格破坏项

同时出现另一套冲突的构图、配色或材质体系，主次对象使用相同对比度，前后景细节密度相同，未请求的文字或伪文字；用户提供文案时不改写、不乱码，全画面霓虹高饱和、荧光渐变与多色同等强调，写实景深、连续圆润三维塑形与镜面高光

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个玻璃拟态风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“半透明面板分层构图、圆角玻璃模块与悬浮界面、冷蓝淡紫与柔白、磨砂玻璃背景模糊与亮边”。

错误写法低饱和克制配色、同时要求彩虹霓虹高饱和

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定玻璃拟态为主风格；冲突属性只保留一项，并明确风格强度。

错误写法玻璃拟态 + Y2K 未来复古 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留玻璃拟态作为结构主导；如需混合，只让Y2K 未来复古负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT
