后印象主义

Post-Impressionism

从印象主义的光色出发，转向更主观的情绪、结构、象征和个人笔触。

一眼识别：强化轮廓、非自然高饱和色、旋转或块面笔触以及主观空间。

01 · CORE DEFINITION

后印象主义解决什么视觉问题

视觉任务从印象主义的光色出发，转向更主观的情绪、结构、象征和个人笔触
解决方式通过压缩但经过明确组织的空间、简化体积、强化轮廓与几何结构、色彩承担明暗与体积塑造把抽象气质转化为稳定、可重复的画面规则。
核心气质高饱和、有机、动态、表现；视觉重点是强化轮廓、非自然高饱和色、旋转或块面笔触以及主观空间。
边界它不等于简单加入“后印象主义元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别后印象主义

强化轮廓、非自然高饱和色、旋转或块面笔触以及主观空间。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图主观透视、色块分区、节奏化视线

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量拉开差距，以局部夸张制造动势

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型简化体积、强化轮廓与几何结构

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩脱离自然综合色的主观高纯度配色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线色彩承担明暗与体积塑造

决定空间深度、材质可信度和戏剧程度。

字体手绘标题、朴素展示体

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质压缩但经过明确组织的空间

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；后印象主义需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

压缩但经过明确组织的空间

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“压缩但经过明确组织的空间”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

简化体积、强化轮廓与几何结构

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“简化体积、强化轮廓与几何结构”是否清楚，再补充色彩与材质。

色彩承担明暗与体积塑造

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“色彩承担明暗与体积塑造”塑造主体；不要叠加互相冲突的光源。

脱离自然综合色的主观高纯度配色

作用建立第一情绪、视觉焦点和区域层级。

使用将“脱离自然综合色的主观高纯度配色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

方向性笔触形成连续表面节奏

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“方向性笔触形成连续表面节奏”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

平涂色域与厚涂油彩并置

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“平涂色域与厚涂油彩并置”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#2D5A91

用于背景、最大形体或主要材质，承担后印象主义的整体气质。

辅助色 · 30%#E0B72F

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#D86A36

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“从印象主义的光色出发，转向更主观的情绪、结构、象征和个人笔触”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造兴奋、活力与即时吸引、流动、柔和与生长感、动态感、表现感的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；叙事主题、人物关系与概念设定作为核心内容；主体需要允许主观透视和强化轮廓参与叙事。

传播场景

适合主题明确的品牌主视觉、文化活动、编辑内容和展览传播；使用前应确认风格气质不会压过核心信息。

受众预期

适合重视自然、材料触感、手工价值和生活方式的受众；强调尖端效率或无瑕精度的内容需要谨慎使用。

选择依据

如果内容同时需要“高饱和、有机、动态”，并能让主观透视、钴蓝和厚涂油彩承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

当项目要求完全中性、跨文化无歧义或极高信息效率时，不宜让后印象主义覆盖全部界面；应以轻度借鉴为主。

具体风险

  • 高饱和色同时大面积使用会削弱信息层级，应明确主色和小面积强调色。
  • 不要同时混入过多相邻风格，优先守住主观透视和强化轮廓。
  • 先验证标题、正文和主体在小尺寸下是否清晰，再增加厚涂油彩等表面效果。

07 · COMPARISON

容易与哪些风格混淆

后印象主义 vs 印象主义

后印象主义主观透视；强化轮廓；钴蓝、铬黄；厚涂油彩。

印象主义开放构图；短促笔触；高明度蓝紫、浅绿；可见油画笔触。

关键差异：后印象主义的识别重心是“强化轮廓、非自然高饱和色、旋转或块面笔触以及主观空间”；印象主义则是“破碎短笔触、户外光线、彩色阴影与开放式构图”。先比较空间结构和边缘处理，再比较题材。

后印象主义 vs 野兽派

后印象主义主观透视；强化轮廓；钴蓝、铬黄；厚涂油彩。

野兽派扁平色域；简化轮廓；朱红、钴蓝；可见画布。

关键差异：后印象主义的识别重心是“强化轮廓、非自然高饱和色、旋转或块面笔触以及主观空间”；野兽派则是“任意肤色、互补色强撞、简化轮廓、宽阔笔触和扁平空间”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留主观透视和 #2D5A91 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用主观透视、强化轮廓、钴蓝和厚涂油彩，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循后印象主义，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
主观透视、色块分区、节奏化视线、脱离自然综合色的主观高纯度配色、手绘标题、朴素展示体
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
简化体积、强化轮廓与几何结构、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
主观透视、色块分区、节奏化视线的层级逻辑、脱离自然综合色的主观高纯度配色、局部使用压缩但经过明确组织的空间
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
简化体积、强化轮廓与几何结构、色彩承担明暗与体积塑造、压缩但经过明确组织的空间
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

10 · PROMPT RECIPE

Prompt 配方：逐项控制，而不是只写风格名

主体具体对象 + 动作/状态 + 使用场景；不要只写抽象情绪
构图主观透视、色块分区、节奏化视线
比例主次体量拉开差距，以局部夸张制造动势
造型简化体积、强化轮廓与几何结构
色彩脱离自然综合色的主观高纯度配色；建议面积比例 55/30/15
光线色彩承担明暗与体积塑造
材质压缩但经过明确组织的空间
字体手绘标题、朴素展示体；允许偏心或斜向排列，但必须保持视觉重量平衡
媒介明确写海报、品牌主视觉、数字界面或插画，不让模型自行猜测输出类型
排除项

无关风格混搭，通用模板感，主体与背景层级不清，不可读文字，所有颜色平均抢占注意力

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个后印象主义风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“主观透视、强化轮廓、钴蓝与铬黄、厚涂油彩”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定后印象主义为主风格；冲突属性只保留一项，并明确风格强度。

错误写法后印象主义 + 印象主义 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留后印象主义作为结构主导；如需混合，只让印象主义负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约 1886–1905 年，欧洲语境。主要来源包括印象主义、日本版画与象征主义。
关键转变从印象主义的光色出发，转向更主观的情绪、结构、象征和个人笔触；视觉语言由此集中到压缩但经过明确组织的空间、简化体积、强化轮廓与几何结构、色彩承担明暗与体积塑造。
后续影响野兽派、表现主义、立体主义与现代插画。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
