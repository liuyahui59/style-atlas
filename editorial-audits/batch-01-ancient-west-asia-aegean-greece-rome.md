# 风格详情页深度审查：第一批

- 审查范围：18 条
- 主题范围：古代西亚、印度河、爱琴海、古希腊与古罗马
- 审查维度：年代、概念边界、媒介范围、视觉概括、历史因果、相邻关系、字段映射、引用透明度
- 资料原则：优先采用 The Metropolitan Museum of Art、Encyclopaedia Iranica、Encyclopaedia Britannica 等专业公开资料，并以 Wikipedia 作补充索引；存在学术争议或证据不足时采用限定性表述。

## 本批结论

本批最普遍的问题不是孤立的年份错误，而是把跨越数百年的文明艺术压缩成单一风格，并将某一件名作、某一种媒介或某一地区特征泛化为整个时期。详情页的“来源”“后续影响”和“相邻风格”还存在批量模板污染：17 个扩充条目曾以自指句描述来源，以“当代视觉转译”代替真实影响，并统一错误关联古埃及艺术。

## 按错误类型重构

| 错误类型 | 涉及条目 | 重构要点 |
| --- | --- | --- |
| 范围过宽、内部差异被抹平 | 巴比伦、帕提亚、希腊化、罗马帝国 | 明确多阶段、多中心或多媒介属性；把高识别特征限定到适用阶段、地区或载体。 |
| 单件作品泛化 | 阿卡德 | 将纳拉姆辛胜利碑的上升对角线标为代表性案例，而非全部阿卡德艺术的固定公式。 |
| 单一媒介泛化 | 苏美尔、米诺斯、迈锡尼、希腊几何、萨珊 | 区分镶嵌、壁画、陶器、银器与整个艺术传统，不再用一种材料或构图覆盖全部遗存。 |
| 年代或分期含混 | 亚述、印度河、古典希腊、罗马共和国 | 亚述限定为新亚述宫廷艺术；印度河注明成熟期；古典希腊采用约前480–前323年；罗马共和国将可辨材料重心限定到前3世纪以后。 |
| 术语逻辑偏差 | 希腊东方化、庞贝第一风格 | 解释“东方化”是现代艺术史术语；说明庞贝四风格是现代壁画分类，不能代表同期全部绘画。 |
| 证据不足的线性因果 | 印度河、阿契美尼德、帕提亚 | 对缺乏可证连续谱系的影响明确降格；把交流、综合和地方传统写成多源关系，而非单线继承。 |
| 接受史偏差 | 古典希腊 | 删除“大理石白等于古典”的默认前提，补充古代雕塑与建筑彩绘事实。 |
| 模板关系污染 | 除古典希腊外的 17 个扩充条目 | 逐条重写来源、后续影响与相邻风格，移除自指来源、泛化的当代转译和统一古埃及关联。 |
| 字段错位 | 古典希腊 | 重新对应构图、造型、色彩、光线、材质和字体，修复轮廓被写入色彩、材质被写入字体的问题。 |
| 引用缺失 | 全部 18 条 | 每条新增 2 个公开参考入口，并在静态详情页与站内详情抽屉展示。 |

## 逐条审查状态

1. 苏美尔艺术：已限定为南部美索不达米亚城邦传统；解除“镶嵌等于全部苏美尔艺术”的媒介泛化。
2. 阿卡德艺术：已区分总体王权视觉与单件胜利碑构图。
3. 巴比伦艺术：已区分古巴比伦、加喜特和新巴比伦；蓝色釉砖明确限定到新巴比伦纪念建筑。
4. 亚述艺术：已明确页面实际聚焦前911–前609年的新亚述宫廷艺术。
5. 阿契美尼德波斯艺术：已补充伊朗、两河、埃及和希腊—爱奥尼亚多源工匠体系。
6. 帕提亚艺术：已把强正面性限定为部分地区的重要线索，而非全域规则。
7. 萨珊艺术：已把圆形徽章和成对重复限定到银器、织物等高频媒介。
8. 印度河文明艺术：已注明成熟期和未释读文字；后续影响改为证据不足的谨慎表述。
9. 米诺斯艺术：已扩大媒介范围，并避免以宫殿壁画概括全部艺术。
10. 迈锡尼艺术：已移除“防御性是全部器物属性”的逻辑泛化。
11. 希腊几何风格：已说明其首先是陶器史分期。
12. 希腊东方化风格：已补充跨区域交流机制与术语限制。
13. 希腊古风艺术：已补充时期内部自然观察逐步增强的变化。
14. 古希腊古典艺术：已修正年代、彩绘事实、视觉字段和相邻关系。
15. 希腊化艺术：已补充古典化、私密化和地域混合路线，避免只以戏剧性定义。
16. 罗马共和国艺术：已把维里主义限定到晚期共和国精英肖像。
17. 罗马帝国艺术：已区分公共纪念工程与私人、行省及晚期古代艺术。
18. 庞贝第一风格壁画：已补充“砌筑风格”别称及现代分类边界。
