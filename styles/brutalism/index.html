数字新粗野主义

Digital Neo-Brutalism

用裸露结构、系统字体和故意直接的界面反对过度精致与同质化。

一眼识别：粗边框、硬阴影、默认控件感、巨大文字与明显网格。

01 · CORE DEFINITION

数字新粗野主义解决什么视觉问题

视觉任务用裸露结构、系统字体和故意直接的界面反对过度精致与同质化
解决方式通过裸露刚性的块状网格、超大系统字体与直接层级、粗黑边框与硬切分区把抽象气质转化为稳定、可重复的画面规则。
核心气质几何、网格、强对比、反叛；视觉重点是粗边框、硬阴影、默认控件感、巨大文字与明显网格。
边界它不等于简单加入“数字新粗野主义元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别数字新粗野主义

粗边框、硬阴影、默认控件感、巨大文字与明显网格。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图裸露刚性的块状网格

决定视线从哪里进入、信息按什么顺序被读取。

比例比例服从基础几何和模块关系

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型矩形边框、系统控件、直接符号

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩粗黑边框与硬切分区

决定第一情绪和区域层级，不能只作为最后滤镜。

光线无阴影、无修饰的平面界面

决定空间深度、材质可信度和戏剧程度。

字体超大系统字体与直接层级

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质硬边、无修饰数字表面

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；数字新粗野主义需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

裸露刚性的块状网格

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“裸露刚性的块状网格”搭建大结构，再添加硬边等表面信息。

超大系统字体与直接层级

作用把风格延伸到标题和信息结构，影响阅读顺序与节奏。

使用让“超大系统字体与直接层级”只承担标题和层级；正文仍需满足实际阅读尺寸。

粗黑边框与硬切分区

作用建立第一情绪、视觉焦点和区域层级。

使用将“粗黑边框与硬切分区”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

黑白配荧光强调色

作用建立第一情绪、视觉焦点和区域层级。

使用将“黑白配荧光强调色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

无阴影、无修饰的平面界面

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“无阴影、无修饰的平面界面”塑造主体；不要叠加互相冲突的光源。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#F0EF3D

用于背景、最大形体或主要材质，承担数字新粗野主义的整体气质。

辅助色 · 30%#171715

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#F7F7F4

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“用裸露结构、系统字体和故意直接的界面反对过度精致与同质化”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造精确、清晰与结构感、网格感、冲突、紧张与强烈焦点、反叛、冲撞与非主流态度的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把数字产品概念、内容层级与交互状态；品牌主张、价值立场与核心产品；活动主题、核心观点与行动号召作为核心内容；主体需要允许裸露网格和矩形边框参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“几何、网格、强对比”，并能让裸露网格、黑白和硬边承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

需要长期阅读、低刺激、制度信任或严肃中立表达的场景不宜让数字新粗野主义主导；可只保留色彩或局部材质作为强调。

具体风险

  • 几何秩序过强可能显得僵硬，需要通过尺度变化或留白建立呼吸感。
  • 强对比适合建立焦点，但连续使用会造成视觉疲劳，并可能影响长文本阅读。
  • 反叛语气不适合强调稳定、权威和普适信任的正式沟通。

07 · COMPARISON

容易与哪些风格混淆

数字新粗野主义 vs 瑞士国际主义

数字新粗野主义裸露网格；矩形边框；黑白、荧光强调色；硬边。

瑞士国际主义模数网格；客观摄影；黑白、单一强调色；干净胶印。

关键差异：数字新粗野主义的识别重心是“粗边框、硬阴影、默认控件感、巨大文字与明显网格”；瑞士国际主义则是“严格网格、左对齐、无衬线字体、留白和少量强调色”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留裸露网格和 #F0EF3D 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用裸露网格、矩形边框、黑白和硬边，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循数字新粗野主义，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
裸露刚性的块状网格、粗黑边框与硬切分区、超大系统字体与直接层级
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
矩形边框、系统控件、直接符号、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
裸露刚性的块状网格的层级逻辑、粗黑边框与硬切分区、局部使用硬边、无修饰数字表面
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
矩形边框、系统控件、直接符号、无阴影、无修饰的平面界面、硬边、无修饰数字表面
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

中文 AI 可执行提示词

保持用户指定的主体、数量、动作、场景、身份与叙事关系不变；用户明确指定的构图、镜头、画幅与文字内容优先；不新增主体、人物、道具或叙事元素。以新粗野主义作为唯一主导视觉风格。构图：裸露网格、大尺度矩形区块、强边界与故意紧张的对齐，允许受控越界。造型：仅将用户已有对象处理为厚重块面、直角框、黑色粗轮廓和直接系统控件形态。色彩：黑白灰高对比，加一种酸绿、鲜红或电蓝强调色。光影：平直正面光或明确的硬边投影，不使用柔雾与细腻渐变。材质：粗纸、裸露混凝土、墨块、像素边缘与无修饰数字表面。文字控制：仅在用户要求文字时使用超粗怪诞无衬线字或等宽字，大尺度并严格可读。

English AI-executable prompt

Preserve the user-defined subjects, count, actions, setting, identities, and narrative relationships. User-specified composition, camera, aspect ratio, and exact text take priority. Do not add subjects, props, or story elements. Use Digital Neo-Brutalism as the sole dominant visual style. Required execution details: exposed rigid block grid, oversized system typography and direct hierarchy, heavy black borders and hard divisions, black and white with fluorescent accents, flat interface without shadow or embellishment. Keep composition, form, palette, lighting, and surface treatment coherent. Apply style-appropriate typography only when the user requests text; otherwise add no text.

柔和卡片阴影，精致圆角，粉彩插画，玻璃模糊，装饰花纹，无边界的元素浮动

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个数字新粗野主义风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“裸露网格、矩形边框、黑白与荧光强调色、硬边”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定数字新粗野主义为主风格；冲突属性只保留一项，并明确风格强度。

错误写法数字新粗野主义 + 瑞士国际主义 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留数字新粗野主义作为结构主导；如需混合，只让瑞士国际主义负责一个明确变量，例如色彩或材质。
