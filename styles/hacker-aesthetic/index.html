01 · CORE DEFINITION

黑客美学解决什么视觉问题

解决方式通过等宽字符网格、行列秩序与终端留白、字符密度形成轮廓和灰阶、黑底配单色荧光或低色数文本把抽象气质转化为稳定、可重复的画面规则。

02 · RECOGNITION GUIDE

如何识别黑客美学

等宽字符网格、行列秩序与终端留白；字符密度形成轮廓和灰阶；黑底配单色荧光或低色数文本；屏幕自发光与轻微辉光；低分辨率显示、扫描线与字符采样。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图等宽字符网格、行列秩序与终端留白

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型字符密度形成轮廓和灰阶

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩字符密度形成轮廓和灰阶

决定第一情绪和区域层级，不能只作为最后滤镜。

光线屏幕自发光与轻微辉光

决定空间深度、材质可信度和戏剧程度。

字体等宽字体、命令行层级与原文准确

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质低分辨率显示、扫描线与字符采样

提供触感、媒介和年代线索，增强风格可信度。

装饰密度等宽字符网格、行列秩序与终端留白

控制信息压力与观看速度；黑客美学需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

等宽字符网格、行列秩序与终端留白

作用控制观看速度、信息压力和画面节奏。

使用先划定阅读区，再安排“等宽字符网格、行列秩序与终端留白”；在缩略图和移动端分别检查信息压力。

字符密度形成轮廓和灰阶

作用建立第一情绪、视觉焦点和区域层级。

使用将“字符密度形成轮廓和灰阶”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

黑底配单色荧光或低色数文本

作用建立第一情绪、视觉焦点和区域层级。

使用将“黑底配单色荧光或低色数文本”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

屏幕自发光与轻微辉光

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“屏幕自发光与轻微辉光”塑造主体；不要叠加互相冲突的光源。

低分辨率显示、扫描线与字符采样

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“低分辨率显示、扫描线与字符采样”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

等宽字体、命令行层级与原文准确

作用把风格延伸到标题和信息结构，影响阅读顺序与节奏。

使用让“等宽字体、命令行层级与原文准确”只承担标题和层级；正文仍需满足实际阅读尺寸。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 60%#14171B

用于背景、最大形体或主要材质，承担黑客美学的整体气质。

辅助色 · 30%#34C6C9

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“黑客美学以等宽字符网格、行列秩序与终端留白、字符密度形成轮廓和灰阶和低分辨率显示、扫描线与字符采样建立可跨主体迁移的视觉语言”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造数字感、未来感与技术张力、高识别感、系统化感的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把数字产品概念、内容层级与交互状态；世界观、角色系统与探索空间；活动主题、核心观点与行动号召作为核心内容；主体需要允许等宽字符网格、行列秩序与终端留白和字符密度形成轮廓和灰阶参与叙事。

传播场景

适合设计展览、教育传播、品牌系统与产品说明等需要把观点组织得清楚有序的场景。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“数字、未来、高识别”，并能让等宽字符网格、行列秩序与终端留白、黑底配单色荧光或低色数文本和低分辨率显示、扫描线与字符采样承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

当项目要求完全中性、跨文化无歧义或极高信息效率时，不宜让黑客美学覆盖全部界面；应以轻度借鉴为主。

具体风险

  • 未来感元素更新很快，避免依赖短期流行的霓虹、镀铬或界面装饰。
  • 系统规则应服务内容差异，避免所有页面因为过度一致而失去重点。
  • 不要同时混入过多相邻风格，优先守住等宽字符网格、行列秩序与终端留白和字符密度形成轮廓和灰阶。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留等宽字符网格、行列秩序与终端留白和 #14171B 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用等宽字符网格、行列秩序与终端留白、字符密度形成轮廓和灰阶、黑底配单色荧光或低色数文本和低分辨率显示、扫描线与字符采样，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循黑客美学，仅适合主视觉、封面和沉浸式核心场景。

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个黑客美学风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“等宽字符网格、行列秩序与终端留白、字符密度形成轮廓和灰阶、黑底配单色荧光或低色数文本、低分辨率显示、扫描线与字符采样”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定黑客美学为主风格；冲突属性只保留一项，并明确风格强度。

错误写法黑客美学 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留黑客美学作为结构主导；如需混合，只让赛博朋克负责一个明确变量，例如色彩或材质。
