01 · CORE DEFINITION

日本画解决什么视觉问题

视觉任务以传统矿物颜料和纸绢材料回应现代绘画制度，兼具细腻观察与平面秩序
解决方式通过平衡克制的浅空间、细腻轮廓与柔和形体概括、分层矿物颜料与低饱和综合色把抽象气质转化为稳定、可重复的画面规则。
核心气质平面、低饱和、克制、写实；视觉重点是柔和矿物色、清晰轮廓、季节自然和哑光纸绢表面。
边界它不等于简单加入“日本画元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别日本画

柔和矿物色、清晰轮廓、季节自然和哑光纸绢表面。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图平衡克制的浅空间

决定视线从哪里进入、信息按什么顺序被读取。

比例主体保持可信比例，以远近尺度变化建立空间

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型细腻轮廓与柔和形体概括

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩柔和矿物色与灰绿色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀柔光与极少硬阴影

决定空间深度、材质可信度和戏剧程度。

字体极简日文题签

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质分层矿物颜料与低饱和综合色

提供触感、媒介和年代线索，增强风格可信度。

装饰密度低密度、少量焦点与大面积呼吸空间

控制信息压力与观看速度；日本画需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

平衡克制的浅空间

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“平衡克制的浅空间”搭建大结构，再添加岩彩和纸哑光质感等表面信息。

细腻轮廓与柔和形体概括

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“细腻轮廓与柔和形体概括”是否清楚，再补充色彩与材质。

分层矿物颜料与低饱和综合色

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“分层矿物颜料与低饱和综合色”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#788B77

用于背景、最大形体或主要材质，承担日本画的整体气质。

辅助色 · 25%#BF8D79

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#D8CFB7

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以传统矿物颜料和纸绢材料回应现代绘画制度，兼具细腻观察与平面秩序”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造平面感、沉静、含蓄与耐看、克制、安静与观看距离、可信、具体与现场感的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；叙事主题、人物关系与概念设定；装饰中的核心主题与叙事对象作为核心内容；主体需要允许安静平衡与浅层空间和细腻自然形态与清晰轮廓参与叙事。

传播场景

适合文化机构、高端品牌、出版专题、静态展陈等允许观众停留和细看内容的场景；强促销环境中需要额外建立焦点。

受众预期

适合关注文化语境、传统工艺和象征含义的受众；跨文化传播时必须解释符号来源，避免把传统元素当作通用装饰。

选择依据

如果内容同时需要“平面、低饱和、克制”，并能让安静平衡与浅层空间、柔和矿物色与灰绿色和岩彩和纸哑光质感承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强促销、节庆、即时行动号召或需要在拥挤环境中抢夺注意力的项目，不适合只使用日本画的低刺激表达。

具体风险

  • 低饱和可能不足以支撑促销、节庆或强行动号召，需要额外的强调色。
  • 过度克制会削弱识别与情绪，在竞争激烈的信息环境中需要更明确的焦点。
  • 写实画面成本较高，快速迭代时应先确定光线、镜头与材质标准。

07 · COMPARISON

容易与哪些风格混淆

日本画 vs 琳派

日本画安静平衡与浅层空间；细腻自然形态与清晰轮廓；柔和矿物色与灰绿色；岩彩和纸哑光质感。

琳派大胆留白与边缘裁切；花鸟流水平面造型；金地群青与朱红；金箔绢本与矿物颜料。

关键差异：日本画的识别重心是“柔和矿物色、清晰轮廓、季节自然和哑光纸绢表面”；琳派则是“金箔背景、成组花鸟、流水曲线、大胆裁切与平面色块”。先比较空间结构和边缘处理，再比较题材。

日本画 vs 浮世绘

日本画安静平衡与浅层空间；细腻自然形态与清晰轮廓；柔和矿物色与灰绿色；岩彩和纸哑光质感。

浮世绘大胆裁切；清晰轮廓；靛蓝、朱红；木版纹理。

关键差异：日本画的识别重心是“柔和矿物色、清晰轮廓、季节自然和哑光纸绢表面”；浮世绘则是“平涂色块、清晰轮廓、非常规裁切与压缩空间”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留安静平衡与浅层空间和 #788B77 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用安静平衡与浅层空间、细腻自然形态与清晰轮廓、柔和矿物色与灰绿色和岩彩和纸哑光质感，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循日本画，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
平衡克制的浅空间、柔和矿物色与灰绿色、极简日文题签
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
细腻轮廓与柔和形体概括、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
平衡克制的浅空间的层级逻辑、柔和矿物色与灰绿色、局部使用分层矿物颜料与低饱和综合色
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
细腻轮廓与柔和形体概括、均匀柔光与极少硬阴影、分层矿物颜料与低饱和综合色
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个日本画风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“安静平衡与浅层空间、细腻自然形态与清晰轮廓、柔和矿物色与灰绿色、岩彩和纸哑光质感”。

错误写法纯平面语言、同时要求写实 3D 体积和镜面高光

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定日本画为主风格；冲突属性只保留一项，并明确风格强度。

错误写法日本画 + 琳派 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留日本画作为结构主导；如需混合，只让琳派负责一个明确变量，例如色彩或材质。

历史脉络

形成背景19 世纪末至今，东亚语境。主要来源包括日本古典绘画与近代美术教育。
关键转变以传统矿物颜料和纸绢材料回应现代绘画制度，兼具细腻观察与平面秩序；视觉语言由此集中到平衡克制的浅空间、细腻轮廓与柔和形体概括、分层矿物颜料与低饱和综合色。
后续影响当代日系插画与出版视觉。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
