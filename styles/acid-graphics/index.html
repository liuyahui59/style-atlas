酸性视觉

Acid Graphics

01 · CORE DEFINITION

酸性视觉解决什么视觉问题

视觉任务以荧光色、液态金属、极端字体和数字噪声制造刺激而反常规的青年视觉
解决方式通过密集越界的边到边布局、液态扭曲与尖锐几何并置、酸绿、电紫与深黑把抽象气质转化为稳定、可重复的画面规则。
核心气质高饱和、反叛、未来、强对比；视觉重点是酸绿荧光色、镀铬变形、尖锐字体、过曝辉光和密集信息。
边界它不等于简单加入“酸性视觉元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别酸性视觉

酸绿荧光色、镀铬变形、尖锐字体、过曝辉光和密集信息。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图密集越界的边到边布局

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型液态扭曲与尖锐几何并置

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩酸绿、电紫与深黑

决定第一情绪和区域层级，不能只作为最后滤镜。

光线低调方向光、局部高光与深阴影

决定空间深度、材质可信度和戏剧程度。

字体数字噪点与极端压缩字体

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质镀铬高光与过曝辉光

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；酸性视觉需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

密集越界的边到边布局

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“密集越界的边到边布局”搭建大结构，再添加镀铬辉光与数字噪点等表面信息。

液态扭曲与尖锐几何并置

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“液态扭曲与尖锐几何并置”是否清楚，再补充色彩与材质。

酸绿、电紫与深黑

作用建立第一情绪、视觉焦点和区域层级。

使用将“酸绿、电紫与深黑”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

镀铬高光与过曝辉光

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“镀铬高光与过曝辉光”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

数字噪点与极端压缩字体

作用把风格延伸到标题和信息结构，影响阅读顺序与节奏。

使用让“数字噪点与极端压缩字体”只承担标题和层级；正文仍需满足实际阅读尺寸。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#B9F227

用于背景、最大形体或主要材质，承担酸性视觉的整体气质。

辅助色 · 30%#BD3EE5

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#202020

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以荧光色、液态金属、极端字体和数字噪声制造刺激而反常规的青年视觉”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造兴奋、活力与即时吸引、反叛、冲撞与非主流态度、未来感与技术张力、冲突、紧张与强烈焦点的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把活动主题、核心观点与行动号召；声音气质、艺人形象与现场氛围；身份态度、廓形语言与材料观念作为核心内容；主体需要允许密集越界与中心爆发构图和液态金属和尖锐变形图形参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“高饱和、反叛、未来”，并能让密集越界与中心爆发构图、酸绿电紫与深黑和镀铬辉光与数字噪点承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

需要长期阅读、低刺激、制度信任或严肃中立表达的场景不宜让酸性视觉主导；可只保留色彩或局部材质作为强调。

具体风险

  • 高饱和色同时大面积使用会削弱信息层级，应明确主色和小面积强调色。
  • 反叛语气不适合强调稳定、权威和普适信任的正式沟通。
  • 未来感元素更新很快，避免依赖短期流行的霓虹、镀铬或界面装饰。

07 · COMPARISON

容易与哪些风格混淆

酸性视觉 vs Y2K 未来复古

酸性视觉密集越界与中心爆发构图；液态金属和尖锐变形图形；酸绿电紫与深黑；镀铬辉光与数字噪点。

Y2K 未来复古中心悬浮；液态曲面；银色、冰蓝；镀铬。

关键差异：酸性视觉的识别重心是“酸绿荧光色、镀铬变形、尖锐字体、过曝辉光和密集信息”；Y2K 未来复古则是“银色镀铬、半透明塑料、椭圆轨道、像素字体与高光渐变”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留密集越界与中心爆发构图和 #B9F227 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用密集越界与中心爆发构图、液态金属和尖锐变形图形、酸绿电紫与深黑和镀铬辉光与数字噪点，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循酸性视觉，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
密集越界的边到边布局、酸绿、电紫与深黑、数字噪点与极端压缩字体
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
液态扭曲与尖锐几何并置、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
密集越界的边到边布局的层级逻辑、酸绿、电紫与深黑、局部使用镀铬高光与过曝辉光
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
液态扭曲与尖锐几何并置、低调方向光、局部高光与深阴影、镀铬高光与过曝辉光
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

10 · PROMPT RECIPE

Prompt 配方：逐项控制，而不是只写风格名

主体具体对象 + 动作/状态 + 使用场景；不要只写抽象情绪
构图密集越界的边到边布局
比例主次体量保持清楚，尺寸差服务视觉层级
造型液态扭曲与尖锐几何并置
色彩酸绿、电紫与深黑；建议面积比例 55/30/15
光线低调方向光、局部高光与深阴影
材质镀铬高光与过曝辉光
字体极端压缩实验字体；选择一种主对齐方式贯穿页面，不混用多个视觉轴
媒介明确写海报、品牌主视觉、数字界面或插画，不让模型自行猜测输出类型
排除项

无关风格混搭，通用模板感，主体与背景层级不清，不可读文字，所有颜色平均抢占注意力

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个酸性视觉风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“密集越界与中心爆发构图、液态金属和尖锐变形图形、酸绿电紫与深黑、镀铬辉光与数字噪点”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定酸性视觉为主风格；冲突属性只保留一项，并明确风格强度。

错误写法酸性视觉 + Y2K 未来复古 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留酸性视觉作为结构主导；如需混合，只让Y2K 未来复古负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景2010 年代末至今，全球语境。主要来源包括锐舞文化、Y2K、实验排版和三维软件。
关键转变以荧光色、液态金属、极端字体和数字噪声制造刺激而反常规的青年视觉；视觉语言由此集中到密集越界的边到边布局、液态扭曲与尖锐几何并置、酸绿、电紫与深黑。
后续影响音乐节、潮流品牌与动态图形。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
