阈限空间

Liminal Space Aesthetic

聚焦本应短暂停留却空无一人的过渡空间，触发熟悉、孤独与不安并存的感受。

一眼识别：空走廊、夜间商场、重复门窗、荧光灯和没有人物的深层空间。

01 · CORE DEFINITION

阈限空间解决什么视觉问题

视觉任务聚焦本应短暂停留却空无一人的过渡空间，触发熟悉、孤独与不安并存的感受
解决方式通过深远重复透视、稀疏空置的空间组织、褪色黄绿与冷灰把抽象气质转化为稳定、可重复的画面规则。
核心气质写实、留白、神秘、低饱和；视觉重点是空走廊、夜间商场、重复门窗、荧光灯和没有人物的深层空间。
边界它不等于简单加入“阈限空间元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别阈限空间

空走廊、夜间商场、重复门窗、荧光灯和没有人物的深层空间。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图空旷重复透视构图

决定视线从哪里进入、信息按什么顺序被读取。

比例主体保持可信比例，以远近尺度变化建立空间

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型无人走廊门窗与过渡空间

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩褪色黄绿与冷灰

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀主光配克制阴影，避免无依据的多光源

决定空间深度、材质可信度和戏剧程度。

字体稀少功能标识

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质低保真噪点与轻微失焦

提供触感、媒介和年代线索，增强风格可信度。

装饰密度深远重复透视

控制信息压力与观看速度；阈限空间需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

深远重复透视

作用控制观看速度、信息压力和画面节奏。

作用建立第一情绪、视觉焦点和区域层级。

使用将“平直均匀的冷色人工光”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#B7AD83

用于背景、最大形体或主要材质，承担阈限空间的整体气质。

辅助色 · 25%#6F8586

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#6D665D

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“聚焦本应短暂停留却空无一人的过渡空间，触发熟悉、孤独与不安并存的感受”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造可信、具体与现场感、疏朗、停顿与精神性、神秘感、沉静、含蓄与耐看的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把人物状态、环境线索与时代气氛；数字艺术中的核心主题与叙事对象；世界观、角色系统与探索空间作为核心内容；主体需要允许空旷重复透视构图和无人走廊门窗与过渡空间参与叙事。

传播场景

适合文化机构、高端品牌、出版专题、静态展陈等允许观众停留和细看内容的场景；强促销环境中需要额外建立焦点。

受众预期

适合希望感受到写实、留白、神秘的受众；正式采用前应先用一张核心画面测试主题理解是否准确。

选择依据

如果内容同时需要“写实、留白、神秘”，并能让空旷重复透视构图、褪色黄绿与冷灰和荧光灯噪点旧地毯与塑料承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强促销、节庆、即时行动号召或需要在拥挤环境中抢夺注意力的项目，不适合只使用阈限空间的低刺激表达。

具体风险

  • 写实画面成本较高，快速迭代时应先确定光线、镜头与材质标准。
  • 留白必须与信息优先级配合，不能简单理解为空内容或低信息量。
  • 低饱和可能不足以支撑促销、节庆或强行动号召，需要额外的强调色。

07 · COMPARISON

容易与哪些风格混淆

阈限空间 vs 梦核

阈限空间空旷重复透视构图；无人走廊门窗与过渡空间；褪色黄绿与冷灰；荧光灯噪点旧地毯与塑料。

梦核空旷中心与不合逻辑空间；漂浮物童年符号与巨大天空；柔蓝粉紫与褪色黄；柔焦压缩噪点与旧照片。

关键差异：阈限空间的识别重心是“空走廊、夜间商场、重复门窗、荧光灯和没有人物的深层空间”；梦核则是“空旷草地、漂浮文字、柔焦天空、童年物件和不合逻辑尺度”。先比较空间结构和边缘处理，再比较题材。

阈限空间 vs 黑色电影

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留空旷重复透视构图和 #B7AD83 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用空旷重复透视构图、无人走廊门窗与过渡空间、褪色黄绿与冷灰和荧光灯噪点旧地毯与塑料，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循阈限空间，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
空旷重复透视构图、褪色黄绿与冷灰、稀少功能标识
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
无人走廊门窗与过渡空间、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
空旷重复透视构图的层级逻辑、褪色黄绿与冷灰、局部使用低保真噪点与轻微失焦
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
无人走廊门窗与过渡空间、均匀主光配克制阴影，避免无依据的多光源、低保真噪点与轻微失焦
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

主体具体对象 + 动作/状态 + 使用场景；不要只写抽象情绪

比例主体保持可信比例，以远近尺度变化建立空间

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个阈限空间风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“空旷重复透视构图、无人走廊门窗与过渡空间、褪色黄绿与冷灰、荧光灯噪点旧地毯与塑料”。

错误写法大面积留白、同时填满复杂装饰和密集信息

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定阈限空间为主风格；冲突属性只保留一项，并明确风格强度。

错误写法阈限空间 + 梦核 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留阈限空间作为结构主导；如需混合，只让梦核负责一个明确变量，例如色彩或材质。
