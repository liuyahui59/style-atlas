01 · CORE DEFINITION

赛博朋克解决什么视觉问题

视觉任务以高科技低生活的矛盾想象巨型都市、企业权力、身体改造与地下抵抗
解决方式通过高密度信息层叠、遮挡与强纵深、低调高反差光线与大面积暗部、电青与洋红为主的分离式霓虹配色把抽象气质转化为稳定、可重复的画面规则。
核心气质未来、强对比、满版、戏剧；视觉重点是夜雨城市、密集霓虹招牌、巨构阴影、湿地反光和机械义体。
边界它不等于简单加入“赛博朋克元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别赛博朋克

夜雨城市、密集霓虹招牌、巨构阴影、湿地反光和机械义体。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图低机位巨构、拥挤纵深、人物被城市压缩

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型冷硬清晰边缘与烟雾化远景并置

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩电青与洋红为主的分离式霓虹配色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线低调高反差光线与大面积暗部

决定空间深度、材质可信度和戏剧程度。

字体窄体无衬线、多语种霓虹字、终端字

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质金属、玻璃与潮湿表面的镜面反射

提供触感、媒介和年代线索，增强风格可信度。

装饰密度高密度信息层叠、遮挡与强纵深

控制信息压力与观看速度；赛博朋克需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

高密度信息层叠、遮挡与强纵深

作用控制观看速度、信息压力和画面节奏。

使用先划定阅读区，再安排“高密度信息层叠、遮挡与强纵深”；在缩略图和移动端分别检查信息压力。

低调高反差光线与大面积暗部

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“低调高反差光线与大面积暗部”塑造主体；不要叠加互相冲突的光源。

电青与洋红为主的分离式霓虹配色

作用建立第一情绪、视觉焦点和区域层级。

使用将“电青与洋红为主的分离式霓虹配色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

逆光、轮廓光与局部过曝辉光

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“逆光、轮廓光与局部过曝辉光”塑造主体；不要叠加互相冲突的光源。

金属、玻璃与潮湿表面的镜面反射

半透明数字叠层、扫描纹与色差边缘

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

冷硬清晰边缘与烟雾化远景并置

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#20B7C6

用于背景、最大形体或主要材质，承担赛博朋克的整体气质。

辅助色 · 30%#DA3A91

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#D9CF2F

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以高科技低生活的矛盾想象巨型都市、企业权力、身体改造与地下抵抗”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造未来感与技术张力、冲突、紧张与强烈焦点、拥挤、压迫与持续刺激、戏剧性与悬念的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把世界观、角色冲突与关键场景；世界观、角色系统与探索空间；叙事主题、人物关系与概念设定作为核心内容；主体需要允许低机位巨构和霓虹招牌参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

更容易吸引关注科技文化、青年文化、亚文化或世界观叙事的受众；面向强调稳定与普适信任的人群时，应降低风格强度。

选择依据

如果内容同时需要“未来、强对比、满版”，并能让低机位巨构、电青和雨水反光承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

需要长期阅读、低刺激、制度信任或严肃中立表达的场景不宜让赛博朋克主导；可只保留色彩或局部材质作为强调。

具体风险

  • 未来感元素更新很快，避免依赖短期流行的霓虹、镀铬或界面装饰。
  • 强对比适合建立焦点，但连续使用会造成视觉疲劳，并可能影响长文本阅读。
  • 满版结构容易挤压标题和功能信息，需要预先划定不可侵占的阅读区域。

07 · COMPARISON

容易与哪些风格混淆

赛博朋克 vs 合成波

赛博朋克低机位巨构；霓虹招牌；电青、洋红；雨水反光。

合成波中央地平线；条纹落日；霓虹紫、洋红；VHS 扫描线。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留低机位巨构和 #20B7C6 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用低机位巨构、霓虹招牌、电青和雨水反光，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循赛博朋克，仅适合主视觉、封面和沉浸式核心场景。

必须保留

必须保留

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个赛博朋克风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“低机位巨构、霓虹招牌、电青与洋红、雨水反光”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定赛博朋克为主风格；冲突属性只保留一项，并明确风格强度。

错误写法赛博朋克 + 合成波 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留赛博朋克作为结构主导；如需混合，只让合成波负责一个明确变量，例如色彩或材质。
