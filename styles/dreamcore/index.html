01 · CORE DEFINITION

梦核解决什么视觉问题

视觉任务用熟悉场景的错位、柔焦和低清图像模拟梦境中亲切又不稳定的体验
解决方式通过稀疏中心布局与比例异常的留白区、不合逻辑的尺度、透视与空间连接、柔蓝、粉紫与褪色黄把抽象气质转化为稳定、可重复的画面规则。
核心气质超现实、低保真、神秘、怀旧；视觉重点是空旷草地、漂浮文字、柔焦天空、童年物件和不合逻辑尺度。
边界它不等于简单加入“梦核元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别梦核

空旷草地、漂浮文字、柔焦天空、童年物件和不合逻辑尺度。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图空旷中心与不合逻辑空间

决定视线从哪里进入、信息按什么顺序被读取。

比例稀疏中心布局与比例异常的留白区

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型漂浮物童年符号与巨大天空

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩柔蓝、粉紫与褪色黄

决定第一情绪和区域层级，不能只作为最后滤镜。

光线过曝漫射光、低对比与柔焦边缘

决定空间深度、材质可信度和戏剧程度。

字体模糊低清提示文字

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质低清压缩、色彩漂移与旧照片颗粒

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；梦核需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

稀疏中心布局与比例异常的留白区

作用控制主体的力量感、亲近感以及与环境的关系。

使用在草图阶段先锁定“稀疏中心布局与比例异常的留白区”，再进入细节；比例错误无法靠后期纹理补救。

不合逻辑的尺度、透视与空间连接

作用控制主体的力量感、亲近感以及与环境的关系。

使用在草图阶段先锁定“不合逻辑的尺度、透视与空间连接”，再进入细节；比例错误无法靠后期纹理补救。

柔蓝、粉紫与褪色黄

作用建立第一情绪、视觉焦点和区域层级。

使用将“柔蓝、粉紫与褪色黄”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

过曝漫射光、低对比与柔焦边缘

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“过曝漫射光、低对比与柔焦边缘”塑造主体；不要叠加互相冲突的光源。

低清压缩、色彩漂移与旧照片颗粒

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“低清压缩、色彩漂移与旧照片颗粒”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 60%#8FB8CF

用于背景、最大形体或主要材质，承担梦核的整体气质。

辅助色 · 30%#D8B4CC

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 10%#D8D08A

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“用熟悉场景的错位、柔焦和低清图像模拟梦境中亲切又不稳定的体验”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造超现实感、低保真感、神秘感、怀旧、时间感与文化记忆的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把数字艺术中的核心主题与叙事对象；声音气质、艺人形象与现场氛围；叙事主题、人物关系与概念设定作为核心内容；主体需要允许空旷中心与不合逻辑空间和漂浮物童年符号与巨大天空参与叙事。

传播场景

适合音乐视觉、复古主题活动、文化回顾与青年内容等依赖年代记忆的传播场景；需要明确具体年代，避免通用复古滤镜。

受众预期

适合希望感受到超现实、低保真、神秘的受众；正式采用前应先用一张核心画面测试主题理解是否准确。

选择依据

如果内容同时需要“超现实、低保真、神秘”，并能让空旷中心与不合逻辑空间、柔蓝粉紫与褪色黄和柔焦压缩噪点与旧照片承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强调尖端技术、无瑕精度或高洁净医疗感的场景，需要谨慎使用梦核的旧化与低保真信号。

具体风险

  • 低保真质感可能被理解为制作粗糙，必须让粗粝显得有意而为。
  • 怀旧符号容易变成通用复古滤镜，应确认年代、媒介和材质线索彼此一致。
  • 不要同时混入过多相邻风格，优先守住空旷中心与不合逻辑空间和漂浮物童年符号与巨大天空。

07 · COMPARISON

容易与哪些风格混淆

梦核 vs 怪核

梦核空旷中心与不合逻辑空间；漂浮物童年符号与巨大天空；柔蓝粉紫与褪色黄；柔焦压缩噪点与旧照片。

怪核不稳定中心与异常裁切；眼睛符号乱码与错位物体；脏蓝洋红与酸绿；低清压缩闪光与扫描噪点。

关键差异：梦核的识别重心是“空旷草地、漂浮文字、柔焦天空、童年物件和不合逻辑尺度”；怪核则是“像素化房间、眼睛符号、乱码警告、强闪光和比例异常”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留空旷中心与不合逻辑空间和 #8FB8CF 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用空旷中心与不合逻辑空间、漂浮物童年符号与巨大天空、柔蓝粉紫与褪色黄和柔焦压缩噪点与旧照片，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循梦核，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
空旷中心与不合逻辑空间、柔蓝、粉紫与褪色黄、模糊低清提示文字
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
漂浮物童年符号与巨大天空、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
空旷中心与不合逻辑空间的层级逻辑、柔蓝、粉紫与褪色黄、局部使用低清压缩、色彩漂移与旧照片颗粒
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
漂浮物童年符号与巨大天空、过曝漫射光、低对比与柔焦边缘、低清压缩、色彩漂移与旧照片颗粒
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个梦核风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“空旷中心与不合逻辑空间、漂浮物童年符号与巨大天空、柔蓝粉紫与褪色黄、柔焦压缩噪点与旧照片”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定梦核为主风格；冲突属性只保留一项，并明确风格强度。

错误写法梦核 + 怪核 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留梦核作为结构主导；如需混合，只让怪核负责一个明确变量，例如色彩或材质。
