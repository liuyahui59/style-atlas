第二帝国风格城市街区、公共建筑或住宅按地域分别组织轴线、中央段、屋顶和街道关系；孟莎屋顶、老虎窗、古典柱饰和雕塑仅在具体项目存在时使用；石材、砖、板岩、金属和室内综合色服从真实材料，不固定暖灰金绿；切石、砖、板岩、铸铁、锌或铜屋面、灰泥和雕刻装饰。

关键差异：古典复兴建筑的识别重心是“按具体复兴路线组织轴线、门廊、庭院和公共空间，不以一座神庙立面代表全部；柱式、山花、拱券、穹顶和基座须符合项目尺度与构造，不混搭无依据构件；石、砖、灰泥、综合色饰面和金属本色随地区与项目变化，古代建筑不默认纯白；真实日光显示柱列、墙体和室内序列，避免把硬投影当作古典性的必要条件；切石、砖、灰泥、木、铁钢结构、综合色装饰和真实接缝”；第二帝国风格则是“城市街区、公共建筑或住宅按地域分别组织轴线、中央段、屋顶和街道关系；孟莎屋顶、老虎窗、古典柱饰和雕塑仅在具体项目存在时使用；石材、砖、板岩、金属和室内综合色服从真实材料，不固定暖灰金绿；真实城市日光显示檐口、屋顶和立面层次，室内按实际环境光处理；切石、砖、板岩、铸铁、锌或铜屋面、灰泥和雕刻装饰”。先比较空间结构和边缘处理，再比较题材。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个古典复兴建筑风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“按具体复兴路线组织轴线、门廊、庭院和公共空间，不以一座神庙立面代表全部、柱式、山花、拱券、穹顶和基座须符合项目尺度与构造，不混搭无依据构件、石、砖、灰泥、综合色饰面和金属本色随地区与项目变化，古代建筑不默认纯白、切石、砖、灰泥、木、铁钢结构、综合色装饰和真实接缝”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定古典复兴建筑为主风格；冲突属性只保留一项，并明确风格强度。

错误写法古典复兴建筑 + 新古典主义 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留古典复兴建筑作为结构主导；如需混合，只让新古典主义负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约18世纪中期至20世纪，包含多个复兴阶段，全球语境。主要来源包括古希腊罗马建筑、文艺复兴古典主义、启蒙时代考古、学院教育和国家公共建筑需求。
关键转变古典复兴建筑是对希腊、罗马及文艺复兴古典传统的多次再解释，范围可涵盖新古典主义、Greek Revival等相交但不等同的路线。柱式、山花和对称不是充分定义；考古知识、政治功能、地区材料与现代建造技术会改变古典语汇；视觉语言由此集中到按具体复兴路线组织轴线、门廊、庭院和公共空间，不以一座神庙立面代表全部、柱式、山花、拱券、穹顶和基座须符合项目尺度与构造，不混搭无依据构件、石、砖、灰泥、综合色饰面和金属本色随地区与项目变化，古代建筑不默认纯白。
后续影响19至20世纪政府、博物馆、银行、校园与纪念建筑，以及后续新古典设计。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
