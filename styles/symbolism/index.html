象征主义

Symbolism

用梦境、神话和私人符号替代直接再现，强调不可见的心理与精神世界。

一眼识别：静止梦境、神秘人物、装饰性金色、隐喻物件和不确定叙事。

01 · CORE DEFINITION

象征主义解决什么视觉问题

视觉任务用梦境、神话和私人符号替代直接再现，强调不可见的心理与精神世界
解决方式通过仪式化中心、镜像或封闭式布局、扁平、悬浮或难以定位的非自然空间、程式化轮廓与隐喻性形体处理把抽象气质转化为稳定、可重复的画面规则。
核心气质象征、低饱和、神秘、装饰；视觉重点是静止梦境、神秘人物、装饰性金色、隐喻物件和不确定叙事。
边界它不等于简单加入“象征主义元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别象征主义

静止梦境、神秘人物、装饰性金色、隐喻物件和不确定叙事。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图仪式化中心、镜像或封闭式布局

决定视线从哪里进入、信息按什么顺序被读取。

比例主次体量保持清楚，尺寸差服务视觉层级

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型程式化轮廓与隐喻性形体处理

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩暗金、夜蓝、灰紫与低明度综合色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀主光配克制阴影，避免无依据的多光源

决定空间深度、材质可信度和戏剧程度。

字体文学性衬线、神秘手写体

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质内向漫射光、柔雾边缘与金属箔光泽

提供触感、媒介和年代线索，增强风格可信度。

装饰密度装饰性重复与缓慢连续的线性节奏

控制信息压力与观看速度；象征主义需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

仪式化中心、镜像或封闭式布局

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“仪式化中心、镜像或封闭式布局”搭建大结构，再添加金箔等表面信息。

扁平、悬浮或难以定位的非自然空间

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“扁平、悬浮或难以定位的非自然空间”搭建大结构，再添加金箔等表面信息。

程式化轮廓与隐喻性形体处理

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“程式化轮廓与隐喻性形体处理”是否清楚，再补充色彩与材质。

装饰性重复与缓慢连续的线性节奏

作用控制观看速度、信息压力和画面节奏。

使用先划定阅读区，再安排“装饰性重复与缓慢连续的线性节奏”；在缩略图和移动端分别检查信息压力。

暗金、夜蓝、灰紫与低明度综合色

作用建立第一情绪、视觉焦点和区域层级。

使用将“暗金、夜蓝、灰紫与低明度综合色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

内向漫射光、柔雾边缘与金属箔光泽

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“内向漫射光、柔雾边缘与金属箔光泽”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#AD8B43

用于背景、最大形体或主要材质，承担象征主义的整体气质。

辅助色 · 25%#263B56

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#67556F

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“用梦境、神话和私人符号替代直接再现，强调不可见的心理与精神世界”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造象征感、沉静、含蓄与耐看、神秘感、精致、繁复与连续节奏的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；叙事主题、人物关系与概念设定；活动主题、核心观点与行动号召作为核心内容；主体需要允许仪式化中心和理想化人物参与叙事。

传播场景

适合文化机构、高端品牌、出版专题、静态展陈等允许观众停留和细看内容的场景；强促销环境中需要额外建立焦点。

受众预期

适合期待仪式感、收藏感和丰富视觉体验的受众；偏好极简效率的人群可能感到信息负担。

选择依据

如果内容同时需要“象征、低饱和、神秘”，并能让仪式化中心、暗金和金箔承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

小屏界面、密集数据表格、无障碍优先或制作预算有限的项目不适合完整复刻象征主义；应先降低装饰密度。

具体风险

  • 象征元素依赖文化背景，跨地区传播前需要确认不会产生误读。
  • 低饱和可能不足以支撑促销、节庆或强行动号召，需要额外的强调色。
  • 装饰元素需要服从结构，随意叠加容易只剩表面模仿。

07 · COMPARISON

容易与哪些风格混淆

象征主义 vs 浪漫主义

象征主义仪式化中心；理想化人物；暗金、夜蓝；金箔。

浪漫主义人物与自然尺度反差；风云与山海；深蓝灰、夕阳金；透明罩染。

关键差异：象征主义的识别重心是“静止梦境、神秘人物、装饰性金色、隐喻物件和不确定叙事”；浪漫主义则是“微小人物面对巨大自然、风暴光线、对角运动和强烈情绪”。先比较空间结构和边缘处理，再比较题材。

象征主义 vs 超现实主义

象征主义仪式化中心；理想化人物；暗金、夜蓝；金箔。

超现实主义空旷舞台；物体变形；冷蓝、沙色；光滑写实。

关键差异：象征主义的识别重心是“静止梦境、神秘人物、装饰性金色、隐喻物件和不确定叙事”；超现实主义则是“写实物体的反常组合、尺度错置、空旷空间与梦境光线”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留仪式化中心和 #AD8B43 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用仪式化中心、理想化人物、暗金和金箔，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循象征主义，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
仪式化中心、镜像或封闭式布局、暗金、夜蓝、灰紫与低明度综合色、文学性衬线、神秘手写体
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
程式化轮廓与隐喻性形体处理、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
仪式化中心、镜像或封闭式布局的层级逻辑、暗金、夜蓝、灰紫与低明度综合色、局部使用内向漫射光、柔雾边缘与金属箔光泽
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
程式化轮廓与隐喻性形体处理、均匀主光配克制阴影，避免无依据的多光源、内向漫射光、柔雾边缘与金属箔光泽
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个象征主义风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“仪式化中心、理想化人物、暗金与夜蓝、金箔”。

错误写法低饱和克制配色、同时要求彩虹霓虹高饱和

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定象征主义为主风格；冲突属性只保留一项，并明确风格强度。

错误写法象征主义 + 浪漫主义 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留象征主义作为结构主导；如需混合，只让浪漫主义负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约 1880–1910 年，欧洲语境。主要来源包括浪漫主义、神秘学与现代心理探索。
关键转变用梦境、神话和私人符号替代直接再现，强调不可见的心理与精神世界；视觉语言由此集中到仪式化中心、镜像或封闭式布局、扁平、悬浮或难以定位的非自然空间、程式化轮廓与隐喻性形体处理。
后续影响新艺术运动、超现实主义、奇幻艺术与电影美术。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
