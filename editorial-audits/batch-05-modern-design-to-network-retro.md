## 本批结论

本批横跨历史设计运动、后来形成的收藏分类、界面原则和网络亚文化。原内容最大问题是把这些不同层级都当成固定“风格包”：中世纪现代是后设宽泛标签，拟物化是长期设计原则，复古未来主义是当代回看旧未来的框架，而酸性图形是非正式行业标签。它们都不适合用单一配色、字体和纹理定义。

此外，建筑粗野主义和网页粗野主义虽然共享名称，却不是直接等价的视觉体系；Synthwave和Vaporwave也不是实际1980或1990年代设计，而是21世纪网络音乐文化对旧媒体的重构。

## 按错误类型重构

| 错误类型 | 涉及条目 | 重构要点 |
| --- | --- | --- |
| 后设标签被写成历史运动 | 中世纪现代、复古未来主义 | 明确名称的后来归纳性质；要求视觉转译说明所引用的具体年代和地域。 |
| 设计原则被缩成年代风格 | 拟物化、扁平设计 | 拟物化远早于智能手机；扁平设计不禁止全部阴影和层级，需保留可用性。 |
| 同名概念混淆 | 建筑粗野主义、网页粗野主义 | 分开建筑的材料和结构伦理与网页对商业模板化的反应，不建立伪直接传承。 |
| 单一商品印象泛化 | 斯堪的纳维亚现代、中世纪现代 | 删除“浅木白墙”“芥末青绿”等必然条件，补充不同国家、材料和媒介。 |
| 单一配色或图案泛化 | 瑞士国际主义、装饰艺术分支、原子时代、孟菲斯 | 黑白红、黑金、回旋镖、粉彩点阵均限定为常见路线而非定义。 |
| 历史语境缺失 | 原子时代、朋克、Grunge | 补充冷战与核焦虑、城市和政治差异、音乐及出版技术语境。 |
| 非正式标签伪精确 | 酸性图形 | 明确不是有宣言、成员和固定起止年的艺术运动，并与acid house、迷幻艺术区分。 |
| 技术史起点错误 | 故障艺术 | 补充1960年代电子媒介先例，数字实践在1990年代后扩展；强调具体故障过程。 |
| 网络怀旧与真实年代混淆 | Synthwave、Vaporwave | 明确二者为21世纪音乐及视觉文化，不能作为真实1980或1990年代设计史替代品。 |
| 字体实验被误解为不可读 | 新浪潮字体、朋克、Grunge、网页粗野主义 | 保留张力和DIY语言，同时要求关键信息、链接和操作状态准确可读。 |
| 六维字段错位或缺项 | 18 条 | 统一重建构图、造型、色彩、光线、材质、字体。 |
| 引用缺失 | 18 条 | 每条新增两项 HTTPS 专业或公开交叉来源。 |

## 逐条审查状态

1. 瑞士国际主义：已解除Helvetica、左齐、红黑白对整个体系的替代。
2. 中世纪现代：已明确为后设宽泛标签，并扩展到建筑、家具、室内和平面。
3. 斯堪的纳维亚现代：已补充北欧各国差异、公共设计和深色材料路线。
4. 流线型现代：已区分真实空气动力功能与象征性流线造型。
5. 原子时代：已补充冷战、核焦虑及1957年后太空竞赛的时间限定。
6. 建筑粗野主义：已补充砖、钢、玻璃等材料，解除灰色压迫巨构的单一想象。
7. 网页粗野主义：已标明非正式数字标签，并与反设计、建筑粗野主义区分。
8. 新浪潮字体：已强调在网格知识上扩展阅读路径，而非任意破坏可读性。
9. 孟菲斯：已恢复家具和产品设计本体，删除“粉彩图案背景”等价关系。
10. 朋克视觉：已补充城市、乐队、政治和传播差异，黑白红不再是固定配色。
11. Grunge设计：已区分音乐文化和图形设计，并避免将其缩成脏污滤镜。
12. 扁平设计：已补充可发现性风险和后续受控深度，解除“绝不使用阴影”的绝对规则。
13. 拟物化：已改为长期设计原则，2007–2013年只作为移动界面高峰。
14. 酸性图形：已标注为非正式行业标签，避免伪造统一运动史。
15. 故障艺术：已将起点前移至电子先例，并按信号、设备、数据和软件过程区分。
16. 复古未来主义：已明确为回看旧未来的框架，视觉必须注明引用年代。
17. Synthwave：已明确为2000年代中期以后音乐文化，霓虹网格只是流行封面惯例。
18. Vaporwave：已明确其网络音乐和消费图像语境，并要求日文和来源文字准确。
