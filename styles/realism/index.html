现实主义

Realism

拒绝神话理想化，将劳动者、城市生活和日常现场置于严肃艺术中心。

一眼识别：平视普通人物、土色调、扎实重量感和不加美化的现实细节。

01 · CORE DEFINITION

现实主义解决什么视觉问题

视觉任务拒绝神话理想化，将劳动者、城市生活和日常现场置于严肃艺术中心
解决方式通过平视观察式取景与稳定构图、未经理想化的自然比例、准确重量感与克制的体积塑造把抽象气质转化为稳定、可重复的画面规则。
核心气质写实、低饱和、叙事、克制；视觉重点是平视普通人物、土色调、扎实重量感和不加美化的现实细节。
边界它不等于简单加入“现实主义元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别现实主义

平视普通人物、土色调、扎实重量感和不加美化的现实细节。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图平视观察式取景与稳定构图

决定视线从哪里进入、信息按什么顺序被读取。

比例未经理想化的自然比例

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型准确重量感与克制的体积塑造

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩土褐、灰绿与低饱和综合色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线均匀自然光与可辨的局部阴影

决定空间深度、材质可信度和戏剧程度。

字体朴素衬线、报刊式标题

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质材质差异由色调和笔触直接呈现

提供触感、媒介和年代线索，增强风格可信度。

装饰密度低密度、少量焦点与大面积呼吸空间

控制信息压力与观看速度；现实主义需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

平视观察式取景与稳定构图

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“平视观察式取景与稳定构图”搭建大结构，再添加厚实油彩等表面信息。

未经理想化的自然比例

作用控制主体的力量感、亲近感以及与环境的关系。

使用在草图阶段先锁定“未经理想化的自然比例”，再进入细节；比例错误无法靠后期纹理补救。

准确重量感与克制的体积塑造

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“准确重量感与克制的体积塑造”是否清楚，再补充色彩与材质。

均匀自然光与可辨的局部阴影

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“均匀自然光与可辨的局部阴影”塑造主体；不要叠加互相冲突的光源。

土褐、灰绿与低饱和综合色

作用建立第一情绪、视觉焦点和区域层级。

使用将“土褐、灰绿与低饱和综合色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

材质差异由色调和笔触直接呈现

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“材质差异由色调和笔触直接呈现”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

厚实可见但不过度装饰的油画笔触

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“厚实可见但不过度装饰的油画笔触”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 70%#6C5942

用于背景、最大形体或主要材质，承担现实主义的整体气质。

辅助色 · 25%#66705C

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 5%#BFB59F

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“拒绝神话理想化，将劳动者、城市生活和日常现场置于严肃艺术中心”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造可信、具体与现场感、沉静、含蓄与耐看、叙事感、克制、安静与观看距离的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；人物状态、环境线索与时代气氛；叙事主题、人物关系与概念设定作为核心内容；主体需要允许平视视角和真实体态参与叙事。

传播场景

适合文化机构、高端品牌、出版专题、静态展陈等允许观众停留和细看内容的场景；强促销环境中需要额外建立焦点。

受众预期

适合希望感受到写实、低饱和、叙事的受众；正式采用前应先用一张核心画面测试主题理解是否准确。

选择依据

如果内容同时需要“写实、低饱和、叙事”，并能让平视视角、土褐和厚实油彩承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

强促销、节庆、即时行动号召或需要在拥挤环境中抢夺注意力的项目，不适合只使用现实主义的低刺激表达。

具体风险

  • 写实画面成本较高，快速迭代时应先确定光线、镜头与材质标准。
  • 低饱和可能不足以支撑促销、节庆或强行动号召，需要额外的强调色。
  • 过度克制会削弱识别与情绪，在竞争激烈的信息环境中需要更明确的焦点。

07 · COMPARISON

容易与哪些风格混淆

现实主义 vs 浪漫主义

现实主义平视视角；真实体态；土褐、灰绿；厚实油彩。

浪漫主义人物与自然尺度反差；风云与山海；深蓝灰、夕阳金；透明罩染。

关键差异：现实主义的识别重心是“平视普通人物、土色调、扎实重量感和不加美化的现实细节”；浪漫主义则是“微小人物面对巨大自然、风暴光线、对角运动和强烈情绪”。先比较空间结构和边缘处理，再比较题材。

现实主义 vs 印象主义

现实主义平视视角；真实体态；土褐、灰绿；厚实油彩。

印象主义开放构图；短促笔触；高明度蓝紫、浅绿；可见油画笔触。

关键差异：现实主义的识别重心是“平视普通人物、土色调、扎实重量感和不加美化的现实细节”；印象主义则是“破碎短笔触、户外光线、彩色阴影与开放式构图”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留平视视角和 #6C5942 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用平视视角、真实体态、土褐和厚实油彩，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循现实主义，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
平视观察式取景与稳定构图、土褐、灰绿与低饱和综合色、朴素衬线、报刊式标题
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
准确重量感与克制的体积塑造、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
平视观察式取景与稳定构图的层级逻辑、土褐、灰绿与低饱和综合色、局部使用材质差异由色调和笔触直接呈现
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
准确重量感与克制的体积塑造、均匀自然光与可辨的局部阴影、材质差异由色调和笔触直接呈现
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

10 · PROMPT RECIPE

Prompt 配方：逐项控制，而不是只写风格名

主体具体对象 + 动作/状态 + 使用场景；不要只写抽象情绪
构图平视观察式取景与稳定构图
比例未经理想化的自然比例
造型准确重量感与克制的体积塑造
色彩土褐、灰绿与低饱和综合色；建议面积比例 70/25/5
光线均匀自然光与可辨的局部阴影
材质材质差异由色调和笔触直接呈现
字体朴素衬线、报刊式标题；选择一种主对齐方式贯穿页面，不混用多个视觉轴
媒介明确写海报、品牌主视觉、数字界面或插画，不让模型自行猜测输出类型
排除项

无关风格混搭，通用模板感，主体与背景层级不清，不可读文字，过度霓虹高饱和，塑料感材质与错误反射

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个现实主义风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“平视视角、真实体态、土褐与灰绿、厚实油彩”。

错误写法低饱和克制配色、同时要求彩虹霓虹高饱和

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定现实主义为主风格；冲突属性只保留一项，并明确风格强度。

错误写法现实主义 + 浪漫主义 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留现实主义作为结构主导；如需混合，只让浪漫主义负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约 1840–1880 年，欧洲语境。主要来源包括社会变革、新闻观察与学院艺术反拨。
关键转变拒绝神话理想化，将劳动者、城市生活和日常现场置于严肃艺术中心；视觉语言由此集中到平视观察式取景与稳定构图、未经理想化的自然比例、准确重量感与克制的体积塑造。
后续影响自然主义、社会纪实摄影与电影现实主义。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
