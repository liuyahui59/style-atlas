06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

当项目要求完全中性、跨文化无歧义或极高信息效率时，不宜让荷兰现代排版覆盖全部界面；应以轻度借鉴为主。

具体风险

  • 系统规则应服务内容差异，避免所有页面因为过度一致而失去重点。
  • 不要同时混入过多相邻风格，优先守住非对称网格、强水平垂直轴与照片文字功能分区和基本几何、粗细线条和直接图形符号。
  • 先验证标题、正文和主体在小尺寸下是否清晰，再增加活字、照片网点、胶印纸与清楚裁切等表面效果。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个荷兰现代排版风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“非对称网格、强水平垂直轴与照片文字功能分区、基本几何、粗细线条和直接图形符号、红、黑、白与有限蓝黄、活字、照片网点、胶印纸与清楚裁切”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定荷兰现代排版为主风格；冲突属性只保留一项，并明确风格强度。

错误写法荷兰现代排版 + 瑞士国际主义 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留荷兰现代排版作为结构主导；如需混合，只让瑞士国际主义负责一个明确变量，例如色彩或材质。
