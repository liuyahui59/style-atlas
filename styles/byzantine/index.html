01 · CORE DEFINITION

拜占庭艺术解决什么视觉问题

视觉任务通过正面圣像、金色非现实空间和马赛克光泽，传达超越尘世的宗教权威
解决方式通过严格正面轴线与近似对称、比例由精神等级决定、扁平浅空间与逆透视把抽象气质转化为稳定、可重复的画面规则。
核心气质平面、对称、象征、华丽；视觉重点是正面凝视、扁平圣像、金色背景、细长人物与镶嵌式光芒。
边界它不等于简单加入“拜占庭艺术元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别拜占庭艺术

正面凝视、扁平圣像、金色背景、细长人物与镶嵌式光芒。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图严格正面轴线与近似对称

决定视线从哪里进入、信息按什么顺序被读取。

比例比例由精神等级决定

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型细长圣像、杏仁形光环、轮廓化衣褶

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩金色底、群青、朱红与紫色

决定第一情绪和区域层级，不能只作为最后滤镜。

光线极少自然投影的正面均匀光

决定空间深度、材质可信度和戏剧程度。

字体希腊文碑铭、宗教符号

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质蛋彩平涂、玻璃马赛克与金箔光泽

提供触感、媒介和年代线索，增强风格可信度。

装饰密度高密度连续组织，阅读区需要主动留出

控制信息压力与观看速度；拜占庭艺术需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

严格正面轴线与近似对称

作用组织观看路径和前后关系，是风格成立的结构基础。

扁平浅空间与逆透视

作用组织观看路径和前后关系，是风格成立的结构基础。

使用先用“扁平浅空间与逆透视”搭建大结构，再添加玻璃马赛克等表面信息。

细长比例、明确轮廓与程式化褶线

作用控制主体的力量感、亲近感以及与环境的关系。

使用在草图阶段先锁定“细长比例、明确轮廓与程式化褶线”，再进入细节；比例错误无法靠后期纹理补救。

极少自然投影的正面均匀光

作用建立明暗层级、空间深度和情绪强度。

金色底、群青、朱红与紫色

作用建立第一情绪、视觉焦点和区域层级。

使用将“金色底、群青、朱红与紫色”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

蛋彩平涂、玻璃马赛克与金箔光泽

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“蛋彩平涂、玻璃马赛克与金箔光泽”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#C9A13A

用于背景、最大形体或主要材质，承担拜占庭艺术的整体气质。

辅助色 · 30%#204B78

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#763E59

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“通过正面圣像、金色非现实空间和马赛克光泽，传达超越尘世的宗教权威”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造平面感、对称感、象征感、丰盛、仪式感与感官刺激的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把情绪、观念与视觉实验；空间秩序、材料观念与公共体验；装饰中的核心主题与叙事对象作为核心内容；主体需要允许正面中心和细长圣像参与叙事。

传播场景

适合节庆主视觉、文化展览、收藏包装和沉浸式空间等允许丰富细节展开的场景；小尺寸传播物需要准备简化版本。

受众预期

适合期待仪式感、收藏感和丰富视觉体验的受众；偏好极简效率的人群可能感到信息负担。

选择依据

如果内容同时需要“平面、对称、象征”，并能让正面中心、金色和玻璃马赛克承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

小屏界面、密集数据表格、无障碍优先或制作预算有限的项目不适合完整复刻拜占庭艺术；应先降低装饰密度。

具体风险

  • 对称布局稳定但容易缺少动势，可以用信息层级而不是破坏轴线来制造变化。
  • 象征元素依赖文化背景，跨地区传播前需要确认不会产生误读。
  • 装饰层次过多会让内容退居其次，应把华丽集中在核心画面而非所有触点。

07 · COMPARISON

容易与哪些风格混淆

拜占庭艺术 vs 哥特艺术

拜占庭艺术正面中心；细长圣像；金色、群青；玻璃马赛克。

哥特艺术强烈垂直轴；尖拱；宝石蓝、深红；彩色玻璃。

关键差异：拜占庭艺术的识别重心是“正面凝视、扁平圣像、金色背景、细长人物与镶嵌式光芒”；哥特艺术则是“尖拱、玫瑰窗、纤细垂直线、彩色玻璃与密集叙事细节”。先比较空间结构和边缘处理，再比较题材。

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留正面中心和 #C9A13A 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用正面中心、细长圣像、金色和玻璃马赛克，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循拜占庭艺术，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
严格正面轴线与近似对称、金色底、群青、朱红与紫色、希腊文碑铭、宗教符号
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
细长圣像、杏仁形光环、轮廓化衣褶、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
严格正面轴线与近似对称的层级逻辑、金色底、群青、朱红与紫色、局部使用蛋彩平涂、玻璃马赛克与金箔光泽
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
细长圣像、杏仁形光环、轮廓化衣褶、极少自然投影的正面均匀光、蛋彩平涂、玻璃马赛克与金箔光泽
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个拜占庭艺术风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“正面中心、细长圣像、金色与群青、玻璃马赛克”。

错误写法纯平面语言、同时要求写实 3D 体积和镜面高光

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定拜占庭艺术为主风格；冲突属性只保留一项，并明确风格强度。

错误写法拜占庭艺术 + 哥特艺术 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留拜占庭艺术作为结构主导；如需混合，只让哥特艺术负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景4–15 世纪，欧洲与西亚语境。主要来源包括晚期罗马、东方基督教与宫廷礼仪。
关键转变通过正面圣像、金色非现实空间和马赛克光泽，传达超越尘世的宗教权威；视觉语言由此集中到严格正面轴线与近似对称、比例由精神等级决定、扁平浅空间与逆透视。
后续影响东正教圣像、哥特艺术与俄罗斯宗教视觉。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
