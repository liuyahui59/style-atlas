粗野主义

Brutalism

以裸露结构、清水混凝土和巨型体量表达公共机构与战后重建的直接性。

一眼识别：厚重悬挑、重复窗格、粗糙混凝土、堡垒体量和暴露结构。

01 · CORE DEFINITION

粗野主义解决什么视觉问题

视觉任务以裸露结构、清水混凝土和巨型体量表达公共机构与战后重建的直接性
解决方式通过巨型块状体量与强烈视觉重量、实心体量、深凹空隙与悬挑结构的对比、重复模数、外露承重逻辑与厚重边缘把抽象气质转化为稳定、可重复的画面规则。
核心气质几何、粗粝、宏大、强对比；视觉重点是厚重悬挑、重复窗格、粗糙混凝土、堡垒体量和暴露结构。
边界它不等于简单加入“粗野主义元素”。如果构图、比例、色彩与材质没有同时遵循同一逻辑，结果只会像表面模仿。

02 · RECOGNITION GUIDE

如何识别粗野主义

厚重悬挑、重复窗格、粗糙混凝土、堡垒体量和暴露结构。 判断时不要只看题材，要逐项核对下面的视觉结构。

构图巨型模块堆叠、重复结构网格、深重阴影

决定视线从哪里进入、信息按什么顺序被读取。

比例巨型块状体量与强烈视觉重量

决定主体的力量感、亲近感以及人与空间的关系。

轮廓与造型重复模数、外露承重逻辑与厚重边缘

决定风格在缩略图和纯剪影状态下是否仍可识别。

色彩灰色单色与极少材料色偏

决定第一情绪和区域层级，不能只作为最后滤镜。

光线深凹阴影、硬质侧光或阴天漫射光

决定空间深度、材质可信度和戏剧程度。

字体粗体无衬线、建筑标识字

把风格延伸到信息层级；文字与图像必须属于同一系统。

材质未修饰清水混凝土、模板接缝与粗骨料纹理

提供触感、媒介和年代线索，增强风格可信度。

装饰密度中等装饰密度，重点区域与安静区域交替

控制信息压力与观看速度；粗野主义需要在识别度和可读性之间保持平衡。

03 · KEY VISUAL GENES

关键视觉基因：特征、作用与使用方式

生成或设计时至少选择三项共同工作，不要只复制一个表面符号。

巨型块状体量与强烈视觉重量

作用控制主体的力量感、亲近感以及与环境的关系。

实心体量、深凹空隙与悬挑结构的对比

作用控制主体的力量感、亲近感以及与环境的关系。

使用在草图阶段先锁定“实心体量、深凹空隙与悬挑结构的对比”，再进入细节；比例错误无法靠后期纹理补救。

重复模数、外露承重逻辑与厚重边缘

作用建立缩略图级别的识别度，决定主体看起来如何。

使用用纯黑剪影检查“重复模数、外露承重逻辑与厚重边缘”是否清楚，再补充色彩与材质。

灰色单色与极少材料色偏

作用建立第一情绪、视觉焦点和区域层级。

使用将“灰色单色与极少材料色偏”落实为主色、辅助色和强调色面积，不要让所有颜色平均竞争。

深凹阴影、硬质侧光或阴天漫射光

作用建立明暗层级、空间深度和情绪强度。

使用先确定唯一主光方向，再用“深凹阴影、硬质侧光或阴天漫射光”塑造主体；不要叠加互相冲突的光源。

未修饰清水混凝土、模板接缝与粗骨料纹理

作用提供媒介、触感与年代线索，避免画面只有抽象形状。

使用把“未修饰清水混凝土、模板接缝与粗骨料纹理”附着到合理对象和表面，不要作为统一滤镜覆盖文字与留白。

04 · COLOR SYSTEM

常见配色方案与使用比例

比例是起始建议，不是硬性规范。先用面积建立层级，再根据媒介明度和可读性微调。

主色 · 55%#8D8B84

用于背景、最大形体或主要材质，承担粗野主义的整体气质。

辅助色 · 30%#272725

用于区分层级、支撑主体和建立冷暖或明度关系，不与主色平均竞争。

强调色 · 15%#8A4B38

只用于标题、焦点、交互状态或关键细节；面积越小，识别信号越明确。

05 · CONTENT FIT

你的内容适合这种风格吗

先判断要表达的主题、情绪与观看预期，再决定是否使用这种风格。媒介只是载体，不应成为选择风格的唯一理由。

适合表达

这种风格的原始命题是“以裸露结构、清水混凝土和巨型体量表达公共机构与战后重建的直接性”。当你的内容也需要讨论相近的冲突、价值或观看方式时，风格与主题才真正匹配。

适合营造

适合营造精确、清晰与结构感、粗粝感、宏大感、冲突、紧张与强烈焦点的观看感受。它会主动改变信息压力和观看节奏，不只是给画面增加一种气氛。

适合展示

更适合把空间秩序、材料观念与公共体验；空间主题、动线体验与材料氛围；数字产品概念、内容层级与交互状态作为核心内容；主体需要允许巨型模块堆叠和悬挑体块参与叙事。

传播场景

适合发布会主视觉、展览、演出、影视游戏宣发等需要迅速建立强烈印象的场景；不适合要求长时间低刺激阅读的主体页面。

受众预期

适合重视清晰秩序、功能逻辑和现代专业感的受众；需要亲密、随性或手作温度时，应加入更柔和的信号。

选择依据

如果内容同时需要“几何、粗粝、宏大”，并能让巨型模块堆叠、混凝土灰和木模混凝土承担表达任务，这种风格是合适的；如果只是喜欢其中一种颜色，建议轻度借鉴。

06 · UNSUITABLE USES & RISKS

不适用场景与执行风险

慎用场景

需要长期阅读、低刺激、制度信任或严肃中立表达的场景不宜让粗野主义主导；可只保留色彩或局部材质作为强调。

具体风险

  • 几何秩序过强可能显得僵硬，需要通过尺度变化或留白建立呼吸感。
  • 粗粝纹理会降低小字号和细线的清晰度，应将文字置于干净底层。
  • 强对比适合建立焦点，但连续使用会造成视觉疲劳，并可能影响长文本阅读。

07 · COMPARISON

容易与哪些风格混淆

粗野主义 vs 包豪斯

粗野主义巨型模块堆叠；悬挑体块；混凝土灰、炭黑；木模混凝土。

包豪斯非对称平衡；圆方三角；红、黄；平面印刷。

关键差异：粗野主义的识别重心是“厚重悬挑、重复窗格、粗糙混凝土、堡垒体量和暴露结构”；包豪斯则是“圆方三角、原色、清晰层级与功能导向的非对称版式”。先比较空间结构和边缘处理，再比较题材。

粗野主义 vs 数字新粗野主义

08 · STYLE INTENSITY

风格强度变化

轻度借鉴

保留 1–2 个主基因

保留巨型模块堆叠和 #8D8B84 强调色；继续使用项目原有字体和组件，避免加入完整年代装饰。

明显使用

联动 3–4 个变量

同时使用巨型模块堆叠、悬挑体块、混凝土灰和木模混凝土，但保留清晰的信息层级。

视觉主导

统一整套视觉语法

构图、比例、轮廓、光线、色彩、字体和材质全部遵循粗野主义，仅适合主视觉、封面和沉浸式核心场景。

09 · MEDIA TRANSLATION

不同媒介怎样转译

同一种风格进入不同媒介时，应该保留核心基因，同时主动降低与媒介任务冲突的部分。

海报

必须保留
巨型模块堆叠、重复结构网格、深重阴影、灰色单色与极少材料色偏、粗体无衬线、建筑标识字
需要调整
把风格集中到主图和标题；正文保持高可读性，远距离先读到主题，再读到装饰细节。

品牌视觉

必须保留
重复模数、外露承重逻辑与厚重边缘、主辅色比例、一个稳定的材质信号
需要调整
把复杂画面提炼成标志形、色板和版式规则；不要要求每个触点都复刻完整作品。

数字界面

必须保留
巨型模块堆叠、重复结构网格、深重阴影的层级逻辑、灰色单色与极少材料色偏、局部使用未修饰清水混凝土、模板接缝与粗骨料纹理
需要调整
降低装饰密度和纹理强度；正文、按钮、状态色及键盘焦点必须优先满足可读性和一致性。

插画

必须保留
重复模数、外露承重逻辑与厚重边缘、深凹阴影、硬质侧光或阴天漫射光、未修饰清水混凝土、模板接缝与粗骨料纹理
需要调整
允许风格主导造型与气氛，但主体轮廓、叙事动作和前后景关系必须清楚。

11 · PROMPT ERRORS

常见错误 Prompt：问题在哪里，怎样修正

错误写法一个粗野主义风格的海报，高级感，设计感，氛围感

问题：只有风格名和主观形容词，没有告诉模型构图、比例、颜色、光线与材质怎样变化。

修正：至少加入“巨型模块堆叠、悬挑体块、混凝土灰与炭黑、木模混凝土”。

错误写法极简低密度构图、同时要求满版高细节装饰

问题：同一控制维度出现相反要求，模型只能随机选择或折中，结果通常两边都不像。

修正：先确定粗野主义为主风格；冲突属性只保留一项，并明确风格强度。

错误写法粗野主义 + 包豪斯 + 赛博朋克 + 极简主义 + 复古未来主义

问题：堆叠多个风格名称没有说明谁控制构图、谁控制材质，容易产生拼贴式表面符号。

修正：保留粗野主义作为结构主导；如需混合，只让包豪斯负责一个明确变量，例如色彩或材质。

12 · HISTORICAL CONTEXT

历史脉络

形成背景约 1950–1975 年，欧美语境。主要来源包括现代主义、战后公共建设与结构诚实。
关键转变以裸露结构、清水混凝土和巨型体量表达公共机构与战后重建的直接性；视觉语言由此集中到巨型块状体量与强烈视觉重量、实心体量、深凹空隙与悬挑结构的对比、重复模数、外露承重逻辑与厚重边缘。
后续影响后现代建筑、数字新粗野主义与游戏场景。今天使用时应继承这些结构原则，而不是机械复刻年代符号。
