A FEW PRACTICAL THINGS

开始之前

Style Atlas 适合谁？

适合经常收集视觉参考的设计师、AI 创作者和设计学习者。无论关注 UI、海报、品牌还是产品造型，都可以通过自定义分析规则，建立自己的观察与复用方式。

必须连接 AI 才能使用吗？

不需要。导入、整理、浏览和搜索可独立使用。需要图片分析时，再连接已登录的本地 Agent，或配置支持图片的 OpenAI 兼容 API。模型服务的使用费用由所选服务决定。

我的图片会上传到哪里？

图片与索引默认保存在本机。只有你主动开始分析，选中的图片才会交给所选 Agent 或 API；本地 Agent 也可能调用它所使用的远程模型服务。

可以自己定义分析内容吗？

可以。你可以基于官方分析规则创建本地自定义规则，调整提示词和关注内容。自定义规则仅保存在本机，官方规则更新不会覆盖你的自定义规则。

支持哪些图片与系统？

支持 JPG、JPEG、PNG、WebP 和 GIF。目前本页提供 macOS 13 及以上版本的安装包，安装版内置运行环境。
